## 1. Polars：现代 DataFrame

| | pandas | Polars |
|---|--------|--------|
| 内核 | 单核 Python/C | Rust，多线程 |
| 执行 | eager 逐操作 | 可 lazy（先建查询计划，优化后一次执行） |
| API 风格 | 列赋值式（`df["a"] = ...`），链式易产生 SettingWithCopy 事故 | 表达式式（`pl.col("a") * 2`），无行级状态 |
| 空值 | NaN/NaT/None 三套体系 | 统一 null |

表达式 API 一次看懂：

```python
import polars as pl

result = (
    pl.scan_csv("sales.csv")                     # lazy：此刻只是查询计划
    .filter(pl.col("amount") > 0)
    .with_columns((pl.col("price") * pl.col("qty")).alias("total"))
    .group_by("region")
    .agg(pl.col("total").sum().alias("revenue"),
         pl.len().alias("orders"))
    .sort("revenue", descending=True)
    .collect()                                    # 此刻才真正执行
)
```

`scan_csv` + `collect` 的价值：**谓词下推**（filter 被推到读取层，只读需要的行和列）+ 多线程并行。`explain()` 能打印执行计划亲眼看。什么时候回 pandas：依赖 pandas 生态的库（matplotlib 绑定、sklearn 输入）或团队存量。

## 2. NumPy 向量化：把循环下沉到 C

思维转变：**操作整列，不是逐元素**。

```python
import numpy as np

positions = np.array(positions)              # (n, 2)
diff = positions[:, None, :] - positions[None, :, :]   # 广播：(n, 1, 2) - (1, n, 2) → (n, n, 2)
sq = (diff ** 2).sum(axis=-1)                # (n, n)
mask = ~np.eye(len(positions), dtype=bool)   # 排除自身对
total = sq[mask].sum() / 2                   # 每对算了两遍
```

对比 Java：这相当于把 `for` 换成了 Stream——不对，比那更狠：循环体根本不在 Python 里执行，在 NumPy 的 C 内核里。T2-3 题 3 你已经量过加速比。三个基本功：广播（shape 对齐规则）、布尔掩码（代替 if + append）、`axis` 参数（代替手写双层循环）。

## 3. structlog：结构化日志

```python
import structlog

log = structlog.get_logger()
log.info("epoch_done", epoch=3, loss=0.42, lr=0.001)
# {"epoch": 3, "event": "epoch_done", "loss": 0.42, "lr": 0.001, ...}
```

对照 `print` 和手拼 logging 格式串：输出是**键值对**，grep/jq/Loki 都能直接吃，代码里也不用维护格式串。配置一次全局生效：

```python
structlog.configure(
    processors=[structlog.processors.add_log_level,
                structlog.processors.TimeStamper(fmt="iso"),
                structlog.dev.ConsoleRenderer()],   # 终端友好渲染
)
```

## 4. Rich：终端输出

```python
from rich.console import Console
from rich.progress import track
from rich.table import Table

console = Console()
for epoch in track(range(50), description="训练中"):
    ...

table = Table(title="实验对比")
table.add_column("run"); table.add_column("loss")
table.add_row("exp01", "0.42")
console.print(table)
```

训练循环的刚需三件套：`track`（一行进度条）、`Table`（对齐的实验对比）、`Console.print`（语法高亮的 dict/repr）。调试期还提供 `rich.inspect(obj)` 看对象结构。
