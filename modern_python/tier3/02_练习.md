## 题 1：pandas vs Polars 同题对解

起始代码：`exercises/t3_2/make_sales_csv.py`——生成 10 万行带脏数据的销售 CSV（空值、负数金额、乱码分类）。

要求：

1. 生成 CSV 后，分别用 pandas 和 Polars 完成同一份分析（各自一个文件：`pandas_version.py` / `polars_version.py`）：
   - 过滤：`amount > 0` 且 category 在白名单内
   - 派生列：`revenue = price * qty`
   - 聚合：按 region 求 revenue 总和与订单数
   - 排序输出前 5
2. 两版结果**逐值相等**（用断言核对，pandas 侧注意 NaN 与 null 的口径差异，注释说明你如何对齐的）。
3. Polars 版必须用 `scan_csv` + `collect`，并打印 `explain()`，在注释里指出**谓词下推**发生在哪。
4. 各计时（含读文件），耗时写进两个文件顶部注释。

**验收标准**：结果断言通过；两版耗时数据；能口头回答 README 里程碑问题——lazy 在什么场景有收益（提示：不是所有数据规模都有收益，想想为什么）。

## 题 2：NumPy 向量化

起始代码：`exercises/t3_2/naive_stats.py`——朴素滑动平均（O(n·w)）。

要求（写成 `exercises/t3_2/vectorized_stats.py`）：

1. 向量化滑动平均：用 `np.cumsum` 把窗口和变成 O(n)（提示：`cs[i+w] - cs[i]`），再除以 w。
2. `np.allclose` 断言两版结果一致（注意浮点口径，注释说明 cumsum 累积误差的处理）。
3. 用 100 万元素、窗口 1000 计时，加速比写进注释。
4. 加做一道广播题：把 T2-3 的两两距离平方和用**广播 + 布尔掩码**重写一遍（可以直接抄学习文档的思路，但要自己跑通），和朴素版断言一致。

**验收标准**：两组结果一致断言通过；两个加速比数据；广播题能解释 `(n,1,2)-(1,n,2)` 为什么对齐成 `(n,n,2)`。

## 题 3：Rich + structlog 重做训练日志

起始代码：`exercises/t3_2/plain_training_log.py`——裸 print 的训练循环。

要求（写成 `exercises/t3_2/rich_training_log.py`）：

1. `rich.progress.track` 做进度条（进阶：`rich.progress.Progress` 加 loss 的实时刷新）。
2. 每 10 个 epoch 用 `structlog` 打一条结构化日志（epoch/loss/acc/lr 键值对）。
3. 训练结束用 `rich.table.Table` 打印"各 10-epoch 段的平均 loss"对比表。
4. 文件里**零裸 print**（进度条和表格除外）。

**验收标准**：终端输出肉眼可读（自己跑一遍截图存档或描述）；`ruff check` 零告警；structlog 输出为键值对。
