## 题 3：pathlib 重写

文件：`exercises/t1_3/paths.py`

起始代码：

```python
import os

def report(root):
    py_count = 0
    total_lines = 0
    for dirpath, dirnames, filenames in os.walk(root):
        for filename in filenames:
            if filename.endswith(".py"):
                full = os.path.join(dirpath, filename)
                py_count += 1
                with open(full, encoding="utf-8") as f:
                    total_lines += len(f.readlines())
    return py_count, total_lines
```

要求：

1. 用 `pathlib.Path` 重写（`rglob`、`read_text`、`splitlines`）。
2. 原版 `f.readlines()` 把整个文件载入再数行——你的版本顺带修掉这个内存问题（想想逐块读或 `str.count`）。
3. 对 `modern_python/tier1/` 目录跑一遍，打印结果。

**验收标准**：行为与原版一致（行数统计口径在注释中说明）；零 `os.path`；`ruff check` 零告警。
