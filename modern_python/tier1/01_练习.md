## 题 3：订单领域对象建模

从零创建 `exercises/t1_1/order_domain.py`，用 dataclass + Enum 建模：

- `OrderStatus`：`PENDING / PAID / CANCELLED`，用 `Enum + auto()`。
- `OrderItem`（frozen dataclass）：`sku: str`、`unit_price: float`、`quantity: int = 1`。
- `Order`（可变 dataclass）：`order_id: str`、`items: list[OrderItem]`（用 `default_factory=list[OrderItem]`——裸 `list` 在 strict 下会被判为 `list[Unknown]`）、`status` 默认 PENDING；方法 `total() -> float` 返回 `sum(unit_price * quantity)`。
- `mark_paid(order: Order) -> Order`：**不改原对象**，用 `replace()` 返回 status 为 PAID 的副本（对照 Java record 的 `withStatus`）。

**验收标准**：

- pyright strict 零报错；
- 文件底部有演示代码：构造 2 个 item 的订单、调用 `total()` 和 `mark_paid()`，打印结果；
- `mark_paid` 调用后原 order 的 status 仍是 PENDING（frozen 的意义体现出来了）。
