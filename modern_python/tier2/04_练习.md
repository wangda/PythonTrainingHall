## 题 4：hypothesis 攻击你的 Result 容器

对象：T2-2 练习 3 的 `exercises/t2_2/result.py`。新文件 `exercises/t2_4/test_result_properties.py`：

```python
from hypothesis import given, strategies as st

@given(st.integers())
def test_map_identity(value: int):
    assert Ok(value).map(lambda x: x).unwrap() == value
```

要求至少 4 条性质：

1. `map` 恒等（上面这条）。
2. `map` 的复合性：`map(g, map(f, r)) == map(lambda x: g(f(x)), r)`（用两个可交换的纯函数，如 `+1` 和 `*2`——想想为什么这两个能交换，注释说明）。
3. `unwrap_or` 性质：对任意整数 v 和默认 d，`Err(v).unwrap_or(d) == d` 且 `Ok(v).unwrap_or(d) == v`。
4. Err 路径性质：任意字符串错误，`Err(s).unwrap()` 必抛且消息含 `s`。

**验收标准**：默认 100 组随机样例全绿；跑 `uv run pytest --hypothesis-seed=random` 依然全绿（防止"随机碰巧过"）；每条性质注释说明它攻击的是哪类实现错误。
