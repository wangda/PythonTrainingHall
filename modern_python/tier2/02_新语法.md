# T2-2 新语法（3.10–3.13）

> 你在 3.12 上，本主题特性全部可用。目标不是"知道有这东西"，是让它们成为第一反应。

## 1. match/case：结构匹配，不是值开关

```python
def handle(cmd: list) -> None:
    match cmd:
        case ["quit"]:
            print("bye")
        case ["load", path]:                      # 捕获变量
            print(f"loading {path}")
        case ["move", x, y] if x >= 0 and y >= 0:  # 守卫条件
            print(f"move to ({x}, {y})")
        case _:
            print("unknown")
```

能解构任意结构，这是它强于 Java switch 的地方：

```python
# 序列解构（含嵌套）
case ("add", left, right): result = eval(left) + eval(right)
case [first, *rest]: ...

# dict 模式：匹配"至少有这些键"，**rest 收集其余
case {"op": "click", "x": x, **rest}: ...

# class 模式（配合 dataclass/属性）
case Point(x=0, y=0): ...
case OrderItem(sku=sku, quantity=q): ...
```

**最大的坑**：`case x` 永远是捕获新变量，不是匹配已有变量。要匹配常量必须用点号名 `case Status.PAID` 或字面量 `case 0`。

Java 21 switch 对比：

| | Java 21 switch | Python match |
|---|---|---|
| 可匹配 | 原始类型/枚举/String（模式匹配需 sealed 接口） | 任意对象、序列、dict、嵌套结构 |
| 解构 | record deconstruction（受限） | 任意深度嵌套解构 |
| 守卫 | `when` 子句（22+） | `if` 守卫（成熟） |
| 语义 | 值分发为主 | **结构分发**为主 |

## 2. 海象运算符 `:=`：赋值即表达式

```python
# 边读边判，消灭"先赋值再判"的双行式
while (chunk := stream.read(4096)):
    process(chunk)

# 条件里算一次、用两次
if (n := len(items)) > 1000:
    print(f"too many: {n}")

# comprehension 里避免重复计算
[cleaned for raw in data if (cleaned := raw.strip())]
```

判断标准：**消除"同一表达式算两次/写两次"时才用**。为了省一行把赋值塞进条件导致阅读跳行，是负收益。

## 3. zoneinfo：时区进标准库（3.9+）

```python
from datetime import datetime
from zoneinfo import ZoneInfo

local = datetime(2026, 10, 23, 9, 0, tzinfo=ZoneInfo("Asia/Shanghai"))
utc = local.astimezone(ZoneInfo("UTC"))
print(utc)  # 2026-10-23 01:00:00+00:00
```

pytz 彻底过时。规则：**naive datetime 是 bug 温床，创建时就带 tzinfo**。对比 Java 的 `java.time`（`ZonedDateTime`/`Instant`）——Python 的 `datetime` 设计远不如它，`zoneinfo` 只是补了时区库这一块。

## 4. 异常组 `except*`（3.11+）

```python
try:
    async with asyncio.TaskGroup() as tg:   # T2-3 主角
        tg.create_task(fetch("a"))
        tg.create_task(fetch("b"))
except* TimeoutError as eg:                 # 一组异常里挑出特定类型
    for exc in eg.exceptions:
        print(f"timeout: {exc!r}")
```

并发任务会同时抛多个异常，传统 `except` 只能接住第一个。`ExceptionGroup` + `except*` 是配套机制，T2-3 会真正用到。

## 5. 3.12 泛型语法：告别 TypeVar 样板

```python
# 旧写法
T = TypeVar("T")
def first(items: list[T]) -> T: ...

# 3.12：类型参数直接写在方括号里
def first[T](items: list[T]) -> T: ...

class Stack[T]:
    def __init__(self) -> None:
        self._items: list[T] = []
    def push(self, item: T) -> None: ...
    def pop(self) -> T: ...

# 泛型约束
def parse_num[N: (int, float)](raw: str) -> N: ...
```

功能与 TypeVar 等价，可读性完胜。3.12 起新代码一律用新语法。
