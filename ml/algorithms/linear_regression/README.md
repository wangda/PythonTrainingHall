## 常见坑提示

- **增广列**：截距 b 不在正规方程里显式出现——给 X 拼一列全 1 把 b 吸收进 θ，即 `np.column_stack([np.ones(n), x])`（文档 §3.2）。sklearn 不用拼，手写要拼。
- **特征缩放**：梯度下降对特征尺度敏感。面积 40~160 的原始值会让梯度量级爆炸，学习率极难调。照文档 §4.3 先 `x / 100` 再训练（测试里就是这么做的）。
- **学习率**：太大（如 0.5）loss 震荡发散，太小（如 0.001）2000 步爬不到底（文档 §4.4）。判断法：loss 曲线单调下降并躺平 = 正常。
- **矩阵形状**：`X_b` 是 `(n, d)`，`y` 是 `(n,)`，`theta` 是 `(d,)`。报错先看形状：`print(X_b.shape, y.shape)`。
- **浮点比较**：永远用 `np.allclose`，不要用 `==`。
