## 一、标量、向量、矩阵、张量 🟢 必须掌握

### 1.1 它们是什么（直觉）

别被名词吓到。这四个东西你天天在用，只是换了个名字：

| 名词 | 大白话 | 生活类比 | NumPy 对应 | 维度（shape） |
| --- | --- | --- | --- | --- |
| 标量（scalar） | **一个数** | 今天气温 25 度 | 0 维数组 | `()` |
| 向量（vector） | **一排数** | 你的一周步数记录 `[8000, 6500, 12000, ...]` | 1 维数组 | `(7,)` |
| 矩阵（matrix） | **一张表格**（多排数） | 全班 30 个同学 × 5 门课的成绩表 | 2 维数组 | `(30, 5)` |
| 张量（tensor） | **多层表格**（表格摞起来） | 全年级 6 个班，每班一张 30×5 的成绩表 | 3 维及以上数组 | `(6, 30, 5)` |

**关键结论：张量就是"多维数组"，一点都不神秘。** 你在 NumPy 里写过 `np.zeros((3, 4, 5))`，那就是一个 3 阶张量。"张量"只是数学界给"任意维度的数组"起的统一名字：

- 0 阶张量 = 标量
- 1 阶张量 = 向量
- 2 阶张量 = 矩阵
- 3 阶及以上 = 还叫张量

> PyTorch 和 TensorFlow 里所有的数据类型都叫 Tensor，原因就在这：它们处理的数据统一都是多维数组。

### 1.2 为什么 ML/DL/LLM 需要它

**因为计算机不认识"猫""狗""你好"这些概念，它只认识数字。把现实世界的数据变成张量，是一切 ML 的第一步：**

- **一张图片** = 3 阶张量 `(高, 宽, 颜色通道)`。比如 224×224 的彩色照片就是 `(224, 224, 3)`，3 是红绿蓝三个通道。CNN 处理的正是这种东西。
- **一批图片** = 4 阶张量 `(图片数量, 高, 宽, 通道)`，比如 `(32, 224, 224, 3)` 表示 32 张图一批。
- **一句话**（给 LLM 看）= 先把每个词变成一个向量（比如每个词用 768 个数表示），一句话是 20 个词就是矩阵 `(20, 768)`，一批 64 句话就是张量 `(64, 20, 768)`。
- **模型本身** = 一堆矩阵。GPT 里每一层的"权重"就是几个大矩阵，整个模型就是几亿个矩阵里装的几千亿个数字。

### 1.3 怎么用（代码）

```python
import numpy as np

# 标量：0 维，就一个数
s = np.array(25.0)
print(s.shape)   # 输出: ()   ← 空括号表示 0 维

# 向量：1 维，一排数。比如一周的步数
v = np.array([8000, 6500, 12000, 9000, 3000, 15000, 11000])
print(v.shape)   # 输出: (7,)

# 矩阵：2 维，一张表。比如 3 个同学 × 4 门课的成绩
m = np.array([
    [90, 85, 77, 92],   # 同学 A
    [60, 70, 80, 65],   # 同学 B
    [88, 91, 95, 89],   # 同学 C
])
print(m.shape)   # 输出: (3, 4)   ← 3 行 4 列

# 张量：3 维，多张表摞起来。比如 2 个班，每班 3 个同学 × 4 门课
t = np.zeros((2, 3, 4))
print(t.shape)   # 输出: (2, 3, 4)

# 一个数本身是几维，数括号里有几个数字就知道
print(t.ndim)    # 输出: 3
```

**程序员记忆法**：`shape` 里有几个数字，就是几维（几阶张量）。每个数字表示"这一层有多少个格子"。

### 本节小结

- 标量 = 一个数，向量 = 一排数，矩阵 = 一张表，张量 = 任意维度的数组。
- "张量"不神秘，它就是 NumPy 里的 `ndarray`、PyTorch 里的 `Tensor`。
- ML 的一切输入（图片、文本、语音）最终都要变成张量；模型本身也是张量。
- 用 `shape` 和 `ndim` 随时查看数据的维度——这是你以后排查 bug 的第一件武器。

## 二、向量运算 🟢 必须掌握

### 2.1 向量加减法

**是什么**：两排一样长的数，对应位置相加/相减。

$$
[1, 2, 3] + [10, 20, 30] = [11, 22, 33]
$$

**大白话翻译**：左边两个"一排数"，第一个加第一个（1+10=11），第二个加第二个（2+20=22），第三个加第三个（3+30=33）。长度不一样不让加，就像 7 天的步数不能和 5 天的步数对齐相加。

**为什么 ML 需要它**：

- 梯度下降更新参数时：`新参数 = 旧参数 - 学习率 × 梯度`，这个"减"就是向量减法，对几百万个参数每个位置同时减。
- 词向量的经典例子：`国王 - 男人 + 女人 ≈ 女王`，向量的加减能表达语义关系，这是词嵌入（embedding）的基础直觉。

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
print(a + b)   # 输出: [11 22 33]
print(b - a)   # 输出: [ 9 18 27]
```

### 2.2 点积（内积）——最重要的一个运算

**是什么（直觉）**：两个一样长的向量，对应位置相乘，再把所有乘积加起来，得到**一个数**。

$$
\vec{a} \cdot \vec{b} = a_1 b_1 + a_2 b_2 + \cdots + a_n b_n
$$

**大白话翻译**：$\vec{a}$ 和 $\vec{b}$ 是两个向量（两排数），$a_1$ 表示 $\vec{a}$ 里的第 1 个数，$a_1 b_1$ 就是"第 1 个位置的两个数相乘"，省略号表示中间每个位置都这样乘，最后全部加起来。结果是一个标量（一个数），不是向量。

**生活类比——点积 ≈ "打分"**：

假设你在相亲网站填了自己对三个特质的看重程度：`[外貌 3, 性格 5, 收入 2]`（满分 5）。候选人甲的得分是 `[4, 4, 3]`，候选人乙是 `[5, 1, 5]`。

- 甲的点积：$3\times4 + 5\times4 + 2\times3 = 12+20+6 = 38$
- 乙的点积：$3\times5 + 5\times1 + 2\times5 = 15+5+10 = 30$

点积就是"按你的偏好加权的总分"。**两个向量越"合拍"（你重视的维度，对方恰好也高），点积越大。**

**为什么 ML 需要它——点积 = 相似度的度量**：

这是本文最重要的直觉之一。把两件事物都表示成向量后，**点积越大，说明它们越"像"**（方向越一致）：

- **注意力机制（Transformer/LLM 的核心）**：`Q`（Query，我在找什么）和每个 `K`（Key，我是什么）做点积，分数高的 K 对应的词就获得更多"注意力"。读"那只猫饿了，所以它吃了鱼"时，"它"的 Q 和"猫"的 K 点积大，模型就知道"它"指的是"猫"。
- **推荐系统**：用户兴趣向量 · 商品特征向量，分数高的推荐给你。
- **语义搜索**：问题的向量 · 文档的向量，找分数最高的文档。

**几何意义（建立直觉即可）**：点积还和两个向量的**夹角**有关：

$$
\vec{a} \cdot \vec{b} = |\vec{a}| \, |\vec{b}| \cos\theta
$$

**大白话翻译**：$|\vec{a}|$ 是向量 $\vec{a}$ 的长度（下一小节讲），$\theta$（读作 theta）是两个向量的夹角，$\cos$ 是余弦函数（你只需知道：夹角为 0° 时 $\cos=1$，90° 时 $\cos=0$，180° 时 $\cos=-1$）。所以：**方向越接近，点积越大；垂直时点积为 0；方向相反时点积为负。** 也可以理解为：点积度量了"$\vec{a}$ 在 $\vec{b}$ 方向上的投影有多长"，投影越长说明越同向。

```python
import numpy as np

a = np.array([3, 5, 2])   # 你的偏好
b = np.array([4, 4, 3])   # 候选人甲
c = np.array([5, 1, 5])   # 候选人乙

print(np.dot(a, b))   # 输出: 38
print(a @ c)          # 输出: 30   ← @ 是 Python 的矩阵/向量乘法运算符，这里做点积

# 验证"垂直的向量点积为 0"
x = np.array([1, 0])
y = np.array([0, 1])      # x 指向正东，y 指向正北，严格垂直
print(x @ y)              # 输出: 0
```

### 2.3 向量长度（范数）

**是什么（直觉）**：向量的长度，就是"从原点到这个点有多远"。初中你学过勾股定理：直角三角形斜边 $= \sqrt{直角边^2 + 直角边^2}$。向量的长度就是勾股定理推广到任意多维：

$$
|\vec{a}| = \sqrt{a_1^2 + a_2^2 + \cdots + a_n^2}
$$

**大白话翻译**：把向量里每个数平方，全部加起来，再开根号。二维时 $|\vec{a}|=\sqrt{a_1^2+a_2^2}$ 就是勾股定理；三维、768 维同理，只是维度更多。这个长度数学上叫 **L2 范数（norm）**，"范数"就是"长度"的正式说法。

**为什么 ML 需要它**：

- **余弦相似度**：把点积除以两个长度，就消除了"向量长短"的影响，只看方向像不像：$\text{相似度} = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$。语义搜索里常用。
- **损失函数**：很多回归问题的损失是"预测值和真实值之差的向量长度平方"，长度越小误差越小。
- **梯度裁剪（gradient clipping）**：训练 LLM 时如果梯度向量的长度太大就按比例缩小，防止一步跨太猛把模型练崩。

```python
import numpy as np

a = np.array([3, 4])
print(np.linalg.norm(a))   # 输出: 5.0   ← 勾股定理：3² + 4² = 25，开根号得 5

# 余弦相似度
def cosine_similarity(x, y):
    return (x @ y) / (np.linalg.norm(x) * np.linalg.norm(y))

print(cosine_similarity(np.array([1, 0]), np.array([1, 0])))   # 输出: 1.0  完全相同
print(cosine_similarity(np.array([1, 0]), np.array([0, 1])))   # 输出: 0.0  完全无关
```

### 本节小结

- 向量加减：对应位置相加减；梯度下降的参数更新就是向量减法。
- **点积 = 对应位置相乘再求和，结果是一个数，直觉是"相似度/加权总分"**；注意力机制的 `QK^T` 就是在批量算点积。
- 点积的几何意义与夹角有关：越同向越大，垂直为 0。
- 向量长度（L2 范数）= 各元素平方和开根号，本质是勾股定理；用于余弦相似度、损失函数、梯度裁剪。

## 三、矩阵运算 🟢 必须掌握

### 3.1 矩阵加减与数乘

**是什么**：

- 加减：两张一样形状的表格，对应格子相加/相减（和向量一样，只是多了一维）。
- 数乘：一个数乘以整张表格，每个格子都乘一遍。

$$
2 \times \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix} = \begin{bmatrix} 2 & 4 \\ 6 & 8 \end{bmatrix}
$$

**大白话翻译**：$\begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$ 是一个 2 行 2 列的矩阵（方括号是它的标准写法），前面的 2 乘进去，每个格子都翻倍。

**为什么 ML 需要它**：批量调整数据。比如把全班的百分制成绩折算成 5 分制，就是整个成绩矩阵乘以 0.05，一行代码搞定，不用写循环。

```python
import numpy as np

scores = np.array([[90, 85], [60, 70], [88, 91]])
print(scores * 0.05)
# 输出:
# [[4.5  4.25]
#  [3.   3.5 ]
#  [4.4  4.55]]
```

### 3.2 矩阵乘法 —— 全篇最核心的运算

**先建立两种等价的理解，任选一个顺手的记住：**

**理解一：矩阵乘法 = 一次做很多次点积。**

矩阵乘向量：矩阵的**每一行**和向量做点积，每个点积得到一个数，拼成结果向量。

$$
\underbrace{\begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}}_{2\times2\text{ 矩阵}} \underbrace{\begin{bmatrix} 5 \\ 6 \end{bmatrix}}_{\text{向量}} = \begin{bmatrix} 1\times5 + 2\times6 \\ 3\times5 + 4\times6 \end{bmatrix} = \begin{bmatrix} 17 \\ 39 \end{bmatrix}
$$

**大白话翻译**：左边是 2 行 2 列的矩阵，右边是竖着写的向量（列向量，数学的习惯写法）。第一行 `[1, 2]` 和 `[5, 6]` 做点积：$1\times5+2\times6=17$，放在结果第一个位置；第二行 `[3, 4]` 和 `[5, 6]` 做点积：$3\times5+4\times6=39$，放在第二个位置。

**生活类比**：矩阵每一行是一个"评分标准"，向量是"一个候选人"。矩阵乘向量 = 用所有评分标准同时给这个候选人打分。1000 个评分标准（1000 行的矩阵）也是一行代码的事——这就是"一次做很多次点积"。

矩阵乘矩阵也一样：左边每一行和右边每一列做点积，结果放在交叉的格子里。

**理解二：矩阵乘法 = 线性变换（对空间做旋转/拉伸/压缩）。**

把向量看成平面上的一个箭头（从原点指向某个点）。用一个矩阵去乘它，这个箭头会被**旋转、拉长或压扁**，变成一个新的箭头。

最直观的例子——**旋转矩阵**：

$$
R = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}
$$

**大白话翻译**：这是一个"逆时针旋转 $\theta$ 度"的矩阵，$\cos\theta$、$\sin\theta$ 是三角函数值（你不用记公式，知道作用就行）。任何向量左乘这个 $R$，都会在平面上逆时针转 $\theta$ 度，长度不变。

**"线性"是什么意思？** 就是这种变换很"规矩"：直线变换后还是直线，原点不动，网格线不会弯。类比：把一张方格纸整体旋转、均匀拉伸，格子还是平行四边形；但不允许像哈哈镜那样局部扭曲。

**为什么这个视角重要**：神经网络每一层就是对输入做一次线性变换（再过一个激活函数加点"弯"）。深度学习可以理解为：**通过成百上千次温和的旋转、拉伸、投影，把原来搅在一起、分不开的数据，逐渐掰扯成容易区分的样子。**

### 3.3 形状规则 —— 看维度报错的救命知识

**铁律：矩阵乘法要求左边的列数 = 右边的行数。**

$$
\underbrace{A}_{m \times n} \times \underbrace{B}_{n \times p} = \underbrace{C}_{m \times p}
$$

**大白话翻译**：$A$ 是 $m$ 行 $n$ 列，$B$ 是 $n$ 行 $p$ 列。中间两个 $n$ 必须相等（因为点积要求两个向量一样长：$A$ 的一行有 $n$ 个数，$B$ 的一列有 $n$ 个数，正好配对）。结果 $C$ 的形状取"外边的两个数"：$m$ 行 $p$ 列。**记忆口诀：中间消掉，留两边。**

举例：`(32, 784) @ (784, 128) → (32, 128)`。含义：32 张手写数字图片，每张 784 个像素，经过一个权重矩阵变换成 128 个特征——这就是神经网络的一层。

**注意：矩阵乘法不满足交换律**，一般 $AB \neq BA$。类比：先穿袜子再穿鞋 ≠ 先穿鞋再穿袜子，顺序有含义。

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])
v = np.array([5, 6])

print(A @ v)        # 输出: [17 39]   ← 矩阵乘向量，就是每行和 v 做点积

B = np.array([[1, 0],
              [0, 2]])
print(A @ B)
# 输出:
# [[1 4]
#  [3 8]]

# 形状规则实战：X(32,784) @ W(784,128) → (32,128)
X = np.random.randn(32, 784)   # 32 张图，每张 784 像素
W = np.random.randn(784, 128)  # 权重矩阵
print((X @ W).shape)           # 输出: (32, 128)

# 维度不匹配会直接报错——以后在 PyTorch 里天天见：
# np.random.randn(32, 100) @ np.random.randn(784, 128)
# ValueError: matmul: dimension mismatch ...  ← 中间 100 ≠ 784，不允许乘
```

> **以后看到 `RuntimeError: size mismatch` 之类的报错，就画这个公式：** 左边列数 == 右边行数，中间消掉留两边。90% 的维度错误都能这样自查。

### 3.4 转置

**是什么**：把矩阵的行和列对调——第 1 行变成第 1 列，第 2 行变成第 2 列。形状从 $(m, n)$ 变成 $(n, m)$。记号是右上角一个小 $T$：

$$
A = \begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \end{bmatrix} \quad\Rightarrow\quad A^T = \begin{bmatrix} 1 & 4 \\ 2 & 5 \\ 3 & 6 \end{bmatrix}
$$

**大白话翻译**：原来横着排的，现在竖着放。$A$ 是 2 行 3 列，$A^T$（读作"A 转置"）就是 3 行 2 列，格子里的数没变，只是"躺倒"了。

**为什么 ML 需要它**：

- **注意力机制里的 $QK^T$**：$Q$ 和 $K$ 的形状都是 `(词数, 维度)`。要算"每个词和每个词的点积"，需要"行 × 行"配对，而矩阵乘法是"行 × 列"，所以把 $K$ 转置一下变成 `(维度, 词数)`，乘法就合法了：`(词数, 维度) @ (维度, 词数) → (词数, 词数)`——结果正是一个"每个词对其他所有词的注意力分数表"。
- **反向传播**的求导链式法则里会频繁出现转置，把梯度的形状对齐。

```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]])
print(A.T.shape)   # 输出: (3, 2)   ← .T 就是转置
print(A.T)
# 输出:
# [[1 4]
#  [2 5]
#  [3 6]]
```

### 本节小结

- 矩阵加减、数乘：对应格子操作，用于批量缩放数据。
- **矩阵乘法 = 批量点积**（每行 × 每列），也等于**对空间做线性变换**（旋转/拉伸）。神经网络每层都是它。
- **形状铁律：$(m\times n)\times(n\times p) = (m\times p)$，中间相等才能乘，结果留两边。** 这是排查维度报错的核心技能。
- 矩阵乘法一般不可交换顺序（$AB \neq BA$）。
- 转置 = 行列对调；注意力机制的 $QK^T$ 靠它把形状配对。

## 四、矩阵与线性方程组 🟢 必须掌握

### 4.1 从初中的方程到矩阵

你初中学过一元一次方程：$2x + 3 = 7$。也见过二元一次方程组：

$$
\begin{cases} 2x + y = 5 \\ x + 3y = 5 \end{cases}
$$

用矩阵写法，这个方程组可以压缩成一行：

$$
\underbrace{\begin{bmatrix} 2 & 1 \\ 1 & 3 \end{bmatrix}}_{A} \underbrace{\begin{bmatrix} x \\ y \end{bmatrix}}_{\vec{x}} = \underbrace{\begin{bmatrix} 5 \\ 5 \end{bmatrix}}_{\vec{b}}
$$

**大白话翻译**：矩阵 $A$ 装的是所有"系数"（未知数前面的数：第一行 2、1 对应第一个方程的 $2x+y$），$\vec{x}$ 是要求的未知数 $x$、$y$ 竖着排，$\vec{b}$ 是等号右边的结果。用第三节的"矩阵乘法 = 每行做点积"验证：第一行 $[2,1]$ 和 $[x,y]$ 点积是 $2x+y$，正好等于 5——完美对应原方程组。**所以：矩阵乘法就是"一次写下一整个方程组"的简写。**

### 4.2 线性回归就是矩阵乘法

线性回归的模型是：

$$
\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b
$$

**大白话翻译**：$\hat{y}$（读作"y  hat"，表示"预测的 y"）是预测值，$x_1$ 到 $x_n$ 是输入特征（比如房子的面积、房间数、地段评分），$w_1$ 到 $w_n$ 是每个特征的权重（重要性，模型要学的就是它们），$b$ 是偏置（一个兜底的基础值，类似"起评分"）。

**看出来了没？右边的前半部分就是向量 $\vec{w}$ 和 $\vec{x}$ 的点积！** 所以单条数据的预测 = 一个点积加一个数。

如果你有 1000 套房子的数据，把每套房子的特征排成一行，就得到矩阵 $X$（1000 行 n 列），那么：

$$
\hat{\vec{y}} = X\vec{w} + b
$$

**大白话翻译**：1000 条预测 = 一次矩阵乘法搞定（每行是一条数据，和 $\vec{w}$ 做点积），不用写 for 循环。这就是"向量化"，也是 NumPy/PyTorch 快的原因。

### 4.3 神经网络 = 线性变换 + 激活函数，反复叠

一个全连接层（MLP 的基本单元）就是：

$$
\vec{h} = f(W\vec{x} + \vec{b})
$$

**大白话翻译**：$\vec{x}$ 是这一层的输入向量，$W$（大写，因为是矩阵）是权重矩阵，$W\vec{x}$ 是一次线性变换（一堆点积），$\vec{b}$ 是偏置向量，$f$ 是**激活函数**——一个非常简单的"掰弯"操作（比如 ReLU：负数变 0，正数不变），$\vec{h}$ 是输出，传给下一层。

**为什么要激活函数？** 如果只有矩阵乘法，叠 100 层也等于一层（线性变换套线性变换还是线性变换，就像旋转再旋转等于一次旋转）。加入 $f$ 这个"弯折"后，网络才能拟合弯曲的、复杂的关系。**"深度"学习就是把这个公式叠很多层：**

$$
\vec{x} \rightarrow f(W_1\vec{x}+\vec{b}_1) \rightarrow f(W_2\vec{h}_1+\vec{b}_2) \rightarrow \cdots \rightarrow \hat{y}
$$

训练的过程，就是通过梯度下降（下一篇微积分讲）不断微调 $W_1, W_2, \ldots$ 里的每一个数字，让预测 $\hat{y}$ 越来越准。LLM 里几千亿个参数，就是这些矩阵 $W$ 里的数字。

```python
import numpy as np

# 一个全连接层：h = relu(X @ W + b)
def relu(x):
    return np.maximum(0, x)   # 负数归零，正数不变

X = np.random.randn(4, 3)     # 4 条数据，每条 3 个特征
W = np.random.randn(3, 5)     # 这一层把 3 维输入变成 5 维输出
b = np.random.randn(5)

h = relu(X @ W + b)
print(h.shape)   # 输出: (4, 5)   ← (4,3)@(3,5)=(4,5)，形状规则再次验证
```

### 本节小结

- 线性方程组可以写成 $A\vec{x}=\vec{b}$，矩阵乘法就是方程组的简写。
- **线性回归 $\hat{\vec{y}} = X\vec{w}+b$ 就是一次矩阵乘法**：每一行数据与权重做点积。
- **神经网络每一层 = 线性变换 $W\vec{x}+\vec{b}$ + 激活函数 $f$**；激活函数提供"弯折"，否则多层等于一层。
- 深度学习的"参数"，就是这些矩阵里的数字；训练就是调这些数字。

## 五、特征值与特征向量（为 PCA 打地基）🟡 暂时跳过（知道直觉即可）

### 5.1 它是什么（直觉）

回忆第三节：矩阵乘向量 = 把向量（箭头）旋转、拉伸。**绝大多数箭头都会被转走方向。** 但对某个特定矩阵，存在少数"幸运"的箭头——被这个矩阵乘完之后，**方向不变，只是长度被缩放**：

$$
A\vec{v} = \lambda \vec{v}
$$

**大白话翻译**：$A$ 是矩阵，$\vec{v}$（读作"v"）是那个"幸运"的向量，叫**特征向量**；$\lambda$（读作 lambda）是一个数，叫**特征值**，表示这个向量被缩放了多少倍。整个式子读作："用 $A$ 变换 $\vec{v}$，效果等同于直接把 $\vec{v}$ 拉长/缩短 $\lambda$ 倍"——方向没变。

**生活类比**：旋转地球仪时，球面上每个点的位置都变了，**唯独南北极的轴心线方向不变**——轴的方向就是这个"旋转"变换的特征向量，特征值是 1（长度也没变）。

### 5.2 为什么 ML 需要它：PCA 在做什么

**PCA（主成分分析）是数据降维的经典方法**，场景：你有 1000 维的数据，想压成 2 维画图观察，又不丢掉太多信息。

PCA 的做法（直觉版）：

1. 数据的"散布方向"可以用一个矩阵（协方差矩阵，你只需知道它描述数据沿各方向的分散程度）来概括；
2. 找出这个矩阵的**特征向量**——它们正好是数据分散最开的几个方向（"主轴"）；
3. **特征值越大，说明数据沿这个方向散布得越开，这个方向越重要**；
4. 只保留特征值最大的前 2 个方向，把数据投影上去，1000 维就压成了 2 维。

类比：给一支斜着飞的箭拍照片。随便选角度拍，箭可能缩成一个点；但沿着箭杆方向看过去（特征向量方向），照片保留的信息最多。PCA 就是自动找到"信息最多的拍摄角度"。

**你将来会在这些地方再遇到它**：数据预处理降维、可视化高维词向量（把 768 维的词向量压成 2 维画图）、以及理解"t-SNE/UMAP 是 PCA 的非线性亲戚"这类说法。

```python
import numpy as np

A = np.array([[2, 0],
              [0, 3]])   # 一个把 x 方向拉 2 倍、y 方向拉 3 倍的变换

eigenvalues, eigenvectors = np.linalg.eig(A)
print(eigenvalues)    # 输出: [2. 3.]       ← 特征值：各方向被拉的倍数
print(eigenvectors)
# 输出:
# [[1. 0.]      ← 第 1 列 [1,0]：x 轴方向，变换后方向不变（特征向量）
#  [0. 1.]]     ← 第 2 列 [0,1]：y 轴方向，变换后方向不变

# 验证：A @ [0,1] 应该等于 3 * [0,1]（方向不变，拉长 3 倍）
v = np.array([0, 1])
print(A @ v)   # 输出: [0 3]
```

> 🟡 **暂时跳过**：不手算特征值，不背求解公式。记住一句话就够：**特征向量 = 变换下方向不变的方向，特征值 = 该方向上的缩放倍数；PCA 用它们找数据的主要方向。**

### 本节小结

- 特征向量：被矩阵变换后方向不变的向量；特征值：它被缩放的倍数。
- 类比：旋转地球仪时不变的轴心线。
- PCA 的核心思想：找数据散布最开的方向（最大特征值对应的特征向量），沿它们降维。
- 会用 `np.linalg.eig` 看出结果含义即可，不要求手算。

## 六、简单了解：单位矩阵、逆矩阵、SVD 🟡 暂时跳过

### 6.1 单位矩阵 I —— 矩阵里的"数字 1"

**是什么**：对角线上全是 1、其余全是 0 的方阵，记作 $I$：

$$
I = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}
$$

**大白话翻译**：它乘任何矩阵/向量都"什么都不做"：$I A = A$，就像数字里 $1 \times 5 = 5$。

**用在哪**：公式推导里当"占位符"；初始化技巧（比如某些网络把权重初始化为接近单位矩阵，让信号原样传递，训练更稳）；理解逆矩阵的桥梁。

```python
import numpy as np
I = np.eye(3)              # 3×3 单位矩阵
A = np.arange(9).reshape(3, 3)
print((I @ A == A).all())  # 输出: True   ← 乘了等于没乘
```

### 6.2 逆矩阵 A⁻¹ —— "撤销"一次变换

**是什么**：如果矩阵 $A$ 是"旋转 30 度"，那 $A^{-1}$（读作"A 逆"）就是"转回去"。两者相乘等于什么都没做：

$$
A A^{-1} = A^{-1} A = I
$$

**大白话翻译**：$A$ 乘上它的逆，结果是单位矩阵 $I$（啥也不变）。类比数字：$5 \times \frac{1}{5} = 1$，$A^{-1}$ 就相当于 $A$ 的"倒数"。**注意：不是所有矩阵都有逆**（就像 0 没有倒数），比如把平面压扁成一条线的变换就"撤销"不了——信息被压没了。

**用在哪**：理论上可以解方程组 $A\vec{x}=\vec{b} \Rightarrow \vec{x}=A^{-1}\vec{b}$。**但工程上几乎从不真的算逆**（慢且数值不稳定），都是换更稳的算法。你看到 $A^{-1}$ 出现在论文公式里时，知道它表示"逆变换/解方程"就够了。

### 6.3 SVD（奇异值分解）—— 把任意矩阵拆成三步

**是什么**：任何一个矩阵 $A$（不要求方阵）都可以拆成三个矩阵的乘积：

$$
A = U \Sigma V^T
$$

**大白话翻译**：$U$、$V^T$ 是两个"旋转"矩阵，$\Sigma$（读作 sigma）是一个"只有对角线有数"的矩阵，作用是沿各方向拉伸。整句话的意思：**任何线性变换，都能分解成"转一下 → 沿坐标轴拉伸 → 再转一下"三步。** $\Sigma$ 对角线上的数叫**奇异值**，越大说明那个方向越重要——和特征值在 PCA 里的角色非常像。

**用在哪**：

- **PCA 的工程实现**大多直接对数据矩阵做 SVD；
- **模型压缩/低秩近似**：LLM 部署时，把巨大的权重矩阵拆开后，只保留最大的几个奇异值，用两个小矩阵近似原来一个大矩阵，参数变少、推理变快（LoRA 微调也基于"低秩"思想）；
- 推荐系统的经典算法（矩阵分解）也是它的亲戚。

> 🟡 **暂时跳过**：三者都只需"知道是什么、用在哪"。面试或读论文见到不慌即可。

### 本节小结

- 单位矩阵 $I$：矩阵里的 1，乘谁都等于没乘。
- 逆矩阵 $A^{-1}$：撤销 $A$ 的变换，$AA^{-1}=I$；工程上很少真算。
- SVD：任何矩阵 = 旋转 × 拉伸 × 旋转；用于 PCA 实现、模型压缩（低秩近似，LoRA 的思想源头）。

## 自测题

**1.** `np.array([[1,2,3],[4,5,6]])` 是标量、向量、矩阵还是张量？shape 是什么？

**2.** 向量 $\vec{a}=[1,2]$，$\vec{b}=[3,4]$，手算 $\vec{a}\cdot\vec{b}$ 和 $|\vec{a}|$。

**3.** 矩阵 $X$ 形状是 `(64, 512)`，$W$ 形状是 `(256, 512)`，直接算 `X @ W` 会发生什么？如何修改才能乘？结果形状是什么？

**4.** 为什么说"没有激活函数，100 层神经网络等价于 1 层"？

**5.** 用自己的话解释：注意力机制里为什么要算 $QK^T$（提示：从点积的含义和形状规则两方面回答）。

**6.** PCA 找"数据分散最开的方向"，用的是哪个数学对象的什么属性？

### 参考答案

1. 它是矩阵（2 阶张量也对——矩阵是张量的特例）；shape 是 `(2, 3)`，2 行 3 列。
2. 点积 $=1\times3+2\times4=11$；长度 $|\vec{a}|=\sqrt{1^2+2^2}=\sqrt{5}\approx2.24$。
3. 会报维度错误：矩阵乘法要求"左边列数 = 右边行数"，这里 512 ≠ 256。把 $W$ 转置成 `(512, 256)` 再乘：`X @ W.T`，结果形状 `(64, 256)`（中间 512 消掉，留两边 64 和 256）。
4. 线性变换的复合仍是线性变换（旋转+拉伸再套旋转+拉伸，等于一次旋转+拉伸），数学上 $W_2(W_1\vec{x}) = (W_2W_1)\vec{x}$ 可合并成一个矩阵。激活函数引入了非线性"弯折"，层数才有意义。
5. ① 点积度量相似度，$QK^T$ 的每个格子是某个词的 Q 和某个词的 K 的点积，即"每个词对每个词的相关程度"；② 形状上 $Q$、$K$ 都是 `(词数, 维度)`，矩阵乘法要求行×列，转置 $K$ 后 `(词数,维度)@(维度,词数)` 合法，得到 `(词数, 词数)` 的注意力分数表。
6. 协方差矩阵的**特征向量**（方向），按**特征值**大小排序，特征值越大方向越重要。
