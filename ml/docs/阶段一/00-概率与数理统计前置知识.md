## 一、概率的基本直觉

### 1.1 随机试验与概率【必须掌握】

**是什么（直觉）：**

生活中有些事结果是确定的：水烧到 100°C（标准大气压下）会开。有些事结果不确定：抛一枚硬币，可能是正面也可能是反面。这种"结果事先不确定、但所有可能结果的范围确定"的事情，叫**随机试验**（random experiment）。

- 抛硬币：可能结果 = {正面， 反面}
- 掷骰子：可能结果 = {1, 2, 3, 4, 5, 6}

所有可能结果组成的集合叫**样本空间**，其中我们关心的某个结果（或一组结果）叫**事件**。比如"掷出偶数"是一个事件，它包含 {2, 4, 6} 三种结果。

**概率（probability）** 就是给每个事件打一个 0 到 1 之间的分数，表示它发生的可能性：

- 0 = 绝对不可能（掷骰子掷出 7）
- 1 = 必然发生（掷骰子掷出 1~6 中的某个数）
- 0.5 = 一半对一半（公平硬币出正面）

**概率是长期频率。** 这是最要紧的一句大白话：抛一次硬币，结果不可预测；但抛一万次，正面的比例会非常接近 0.5。概率不保证单次结果，只描述"大量重复之后的长期规律"。就像开车：导航说"全程平均时速 60 公里"，不代表你每时每刻都开 60，而是说跑完整段路平均下来是 60。

$$0 \le P(A) \le 1, \qquad P(\text{样本空间}) = 1$$

**大白话翻译：** $P(A)$ 读作"事件 A 发生的概率"。任何事件的概率最小是 0、最大是 1；把所有可能结果打包在一起看，概率必然是 1（总得发生点什么）。

如果事件 $A$ 不发生记作 $\bar{A}$（读作"A 的反面"），那么：

$$P(\bar{A}) = 1 - P(A)$$

**大白话翻译：** "下雨概率 30%"和"不下雨概率 70%"是同一件事的两面，加起来正好 100%。这个"1 减去"的技巧在 ML 里天天用（比如 sigmoid 输出是正类概率，负类概率就是 1 减它）。

**ML 为什么需要它：** 分类模型（逻辑回归、Softmax、LLM 的 next-token 预测）输出的根本不是"答案"，而是"每个类别的概率"。比如 LLM 预测下一个词，输出的是词表里每个词的概率，所有词的概率加起来等于 1。看不懂概率，就看不懂模型的输出。

**怎么用（代码）：**

```python
import numpy as np

rng = np.random.default_rng(seed=42)

# 模拟抛硬币：1 表示正面，0 表示反面
n = 100_000
flips = rng.integers(0, 2, size=n)

print("正面频率:", flips.mean())          # 预期输出: 约 0.5（如 0.5014）
print("前 10 次正面频率:", flips[:10].mean())  # 预期输出: 偏离 0.5 很远（如 0.7）
```

注意两次打印的差别：次数少的时候频率乱飘，次数多了就稳定在 0.5 附近——这就是"概率是长期频率"的直观演示，也是第五节大数定律的预告。

### 1.2 加法规则与"或"【必须掌握】

**是什么：** 掷骰子，"掷出 1 或 2"的概率是多少？两种结果互不冲突（一次只能掷出一个数），直接把概率加起来：$1/6 + 1/6 = 1/3$。

**互斥事件**（不可能同时发生）的加法规则：

$$P(A \text{ 或 } B) = P(A) + P(B) \quad (\text{A、B 互斥})$$

**大白话翻译：** 两件事不可能同时发生（掷一次骰子不可能既是 1 又是 2），那么"发生 A 或 B"的概率就是两个概率相加。

如果可能同时发生（不互斥），加完会重复计算重叠部分，要减掉：

$$P(A \text{ 或 } B) = P(A) + P(B) - P(A \text{ 且 } B)$$

**ML 为什么需要它：** 多分类问题里，"模型预测为猫或狗"的概率就是各类别概率相加；概率归一化（所有类别概率和为 1）就是加法规则+样本空间概率为 1 的直接应用。

### 本节小结

1. 随机试验 = 结果不确定、但可能结果范围确定的事情；概率给每个事件打 0~1 的分数。
2. 概率的核心直觉是**长期频率**：大量重复后，频率会稳定在概率附近。
3. 所有可能结果的概率之和恒等于 1；"不发生"的概率 = 1 − "发生"的概率。
4. 互斥事件的"或"用加法；不互斥要减去重叠部分。
5. ML 分类模型的输出就是一组和为 1 的概率——这是理解一切分类器的第一步。

## 二、条件概率、独立性与贝叶斯公式

### 2.1 条件概率【必须掌握】

**是什么（直觉）：** "明天下雨的概率"和"已知今天乌云密布时，明天下雨的概率"显然不一样。后一个就是**条件概率**（conditional probability）：在已知某件事发生的前提下，另一件事发生的概率。

记作 $P(A|B)$，读作"在 B 发生的条件下，A 发生的概率"。竖线后面是"已知条件"。

$$P(A|B) = \frac{P(A \text{ 且 } B)}{P(B)}$$

**大白话翻译：** 想知道"B 都发生了，A 也发生"的可能性多大？那就只在"B 发生的世界里"看：分子是"A 和 B 同时发生"的概率（交集），分母是"B 发生"的概率（新的全集）。相当于把考察范围从全世界缩小到"B 发生的那部分世界"，再算 A 占多大比例。

**生活例子：** 一个班 40 人，20 个男生 20 个女生；其中 10 个男生戴眼镜、5 个女生戴眼镜。随机抽一人，已知是男生，他戴眼镜的概率？把范围缩小到 20 个男生里看，10 个戴眼镜，所以 $P(\text{眼镜}|\text{男}) = 10/20 = 0.5$。注意这和无条件概率 $P(\text{眼镜}) = 15/40 = 0.375$ 不同——**条件会改变概率**。

**ML 为什么需要它：** 分类器的本质就是计算条件概率 $P(\text{类别}|\text{输入特征})$。垃圾邮件过滤器算的是 $P(\text{垃圾}|\text{邮件里出现"免费""中奖"这些词})$；LLM 生成文本算的是 $P(\text{下一个词}|\text{前面所有词})$。条件概率就是"预测"二字的数学化身。

### 2.2 独立性【必须掌握】

**是什么（直觉）：** 抛两次硬币，第一次的结果不会影响第二次——这两次抛掷是**独立**（independent）的。独立的含义就是"互相不影响，知道一个的结果对预测另一个毫无帮助"。

$$P(A \text{ 且 } B) = P(A) \cdot P(B) \quad (\text{A、B 独立})$$

**大白话翻译：** 两件事互不相干时，"同时发生"的概率 = 各自概率相乘。两次都抛正面的概率 = 0.5 × 0.5 = 0.25。

对照 2.1 的公式可以发现：独立等价于 $P(A|B) = P(A)$——"知道了 B 也改变不了 A 的概率"。

**ML 为什么需要它：** 朴素贝叶斯分类器（经典的垃圾邮件过滤算法）的"朴素"二字，就是假设所有特征相互独立——"免费"和"中奖"在邮件里是否出现被当作互不相干，这样概率就能拆成一个个相乘，计算量从天文数字变成小菜一碟。这个假设明显是假的（词和词当然相关），但效果常常出奇地好，是"简单模型也能打"的经典案例。

### 2.3 贝叶斯公式【必须掌握】

**是什么（直觉）：** 这是本文最重要的一个公式，请慢读。

由 2.1 的公式，$P(A \text{ 且 } B) = P(A|B)\,P(B)$，同理也等于 $P(B|A)\,P(A)$。两式相等，移项就得到**贝叶斯公式**（Bayes' theorem）：

$$P(A|B) = \frac{P(B|A)\,P(A)}{P(B)}$$

**大白话翻译：** 现实中容易统计的往往是"正向"概率 $P(B|A)$（比如"生病的人里，检测呈阳性的比例"，拿一群确诊病人测一测就知道）；但我们真正想要的是"反向"概率 $P(A|B)$（"检测呈阳性的人里，真生病的比例"）。贝叶斯公式就是这台"概率方向反转机"。

**用"生病检测"讲透：**

假设某种病：
- 患病率（人群中真生病的比例）：0.1%，即 $P(\text{病}) = 0.001$
- 灵敏度（病人检测为阳性的概率）：99%，即 $P(\text{阳}|\text{病}) = 0.99$
- 假阳性率（健康人被误判为阳性的概率）：5%，即 $P(\text{阳}|\text{健康}) = 0.05$

现在你体检结果为阳性，你慌不慌？直觉上"99% 灵敏度的检测说我阳了，那我九成九是病了"。**这是错的**，而且错得离谱。用贝叶斯算一下：

$$P(\text{病}|\text{阳}) = \frac{P(\text{阳}|\text{病})\,P(\text{病})}{P(\text{阳}|\text{病})\,P(\text{病}) + P(\text{阳}|\text{健康})\,P(\text{健康})}$$

**大白话翻译：** 分母是"阳性"这件事的全部来源：一部分来自真病人（生病且检出），一部分来自被冤枉的健康人（没病但误报）。分子只是其中"真病人检出"那一部分。整个式子就是问：**在所有阳性结果里，有多少比例是真病人贡献的？**

代入数字：分子 $= 0.99 \times 0.001 = 0.00099$；分母 $= 0.00099 + 0.05 \times 0.999 = 0.05094$。

$$P(\text{病}|\text{阳}) = \frac{0.00099}{0.05094} \approx 0.019 \approx 2\%$$

**结果是 2%，不是 99%！** 为什么？想象一个 10 万人的城市：真病人只有 100 人（检出约 99 个阳性），但健康人有 99900 人，5% 的误报会制造出约 4995 个假阳性。阳性的海洋里（99 + 4995 ≈ 5094 个），真病人（99 个）只是极少数。病太罕见了，罕见事件即使有很准的检测，阳性结果也大多来自误报。

贝叶斯公式里各部分的行话（ML 文献里常见，必须眼熟）：

| 名称 | 符号 | 生病例子里对应 |
|---|---|---|
| 先验（prior） | $P(\text{病})$ | 没做检测前，你生病的概率（0.1%） |
| 似然（likelihood） | $P(\text{阳}\|\text{病})$ | 假设病了，观测到阳性的概率（99%） |
| 后验（posterior） | $P(\text{病}\|\text{阳})$ | 看到阳性结果后，更新的生病概率（2%） |

一句话记住贝叶斯的哲学：**用新证据，把旧看法（先验）更新成新看法（后验）。** 直觉陷阱在于人们总忘记先验——病本身太罕见了。

**ML 为什么需要它：** 这是所有分类器和垃圾邮件过滤的思想源头。朴素贝叶斯分类器就是在对每条数据做这件事：$\text{后验} \propto \text{似然} \times \text{先验}$，然后选后验最大的类别。往深了说，"训练模型"本身就是一种贝叶斯式的更新：看到数据之前你对参数有个模糊认识，看完数据后更新成更确定的认识。

**怎么用（代码）：**

```python
p_sick = 0.001                # 先验：患病率
p_pos_if_sick = 0.99          # 似然：灵敏度
p_pos_if_healthy = 0.05       # 假阳性率
p_healthy = 1 - p_sick

# 全概率：阳性的总概率 = 真病检出 + 健康误报
p_pos = p_pos_if_sick * p_sick + p_pos_if_healthy * p_healthy

# 贝叶斯：阳性中的人里真生病的比例（后验）
p_sick_if_pos = p_pos_if_sick * p_sick / p_pos

print(f"检测阳性后真生病的概率: {p_sick_if_pos:.2%}")  # 预期输出: 约 1.94%
```

### 本节小结

1. 条件概率 $P(A|B)$ = 把考察范围缩小到"B 发生的世界"再算 A 的比例；分类器输出的就是条件概率。
2. 独立 = 互不影响，此时"同时发生"的概率可直接相乘；朴素贝叶斯靠这个假设化繁为简。
3. 贝叶斯公式把 $P(B|A)$ 反转成 $P(A|B)$：后验 ∝ 似然 × 先验。
4. 生病检测例子：罕见病 + 99% 灵敏度，阳性后真病概率只有约 2%——先验（基础概率）绝不能忽略。
5. 贝叶斯是分类器、垃圾邮件过滤的思想源头，也是"用数据更新认知"这一 ML 大主题的数学表达。

## 三、随机变量、期望、方差

### 3.1 随机变量【必须掌握】

**是什么（直觉）：** **随机变量**（random variable）就是"给随机试验的结果贴一个数字标签"。

- 抛硬币：正面记 1，反面记 0。这个"1 或 0"就是随机变量 $X$。
- 掷骰子：点数本身就是随机变量 $X \in \{1,2,3,4,5,6\}$。
- 明天最高气温：随机变量 $T$，取值是连续实数。

为什么要贴数字？因为数字才能参与计算——"正面、反面"没法相加，"1、0"可以。随机变量把随机的世界翻译成了算术的世界。

分两类：**离散型**（取值可以一个个数出来：骰子点数、硬币面）和**连续型**（取值是连续的：温度、身高、体重）。

每个取值（或取值区间）对应一个概率，整套"取值 → 概率"的对照关系叫**概率分布**（distribution），第四节会细讲。

**ML 为什么需要它：** 数据集里的每一列特征、每一个标签，在 ML 眼里都是随机变量的采样。"这张图片是不是猫"是一个伯努利随机变量，"房价"是一个连续随机变量。训练数据 = 对随机变量的一批观测值。

### 3.2 期望【必须掌握】

**是什么（直觉）：** **期望**（expectation，记作 $E[X]$）= 长期平均值。重复试验无数次，结果的算术平均值会稳定在哪个数上，那个数就是期望。

离散型随机变量的期望：

$$E[X] = \sum_{i} x_i \, P(X = x_i)$$

**大白话翻译：** 把每个可能取值 $x_i$ 乘以它发生的概率，再全部加起来。就是"按概率加权的平均值"——概率大的结果话语权大。

**例子 1（掷骰子）：** $E[X] = 1\times\frac{1}{6} + 2\times\frac{1}{6} + \cdots + 6\times\frac{1}{6} = 3.5$。注意骰子永远掷不出 3.5——**期望不一定是可能取值**，它是"长期平均"的锚点。就像"中国家庭平均 2.6 口人"，没有哪家是 2.6 口人，但这个数有意义。

**例子 2（工资，为什么期望会被"带偏"）：** 一个组 5 人月薪：8k、9k、10k、11k、12k，平均（期望）是 10k。现在空降一位月薪 200k 的大佬，期望立刻变成 $(8+9+10+11+12+200)/6 \approx 41.7$k——没有任何一个组员挣到这个数。期望对**极端值非常敏感**，这就是为什么"平均工资"总是比你感觉的高。

期望的两个好用性质（$a, b$ 是常数）：

$$E[aX + b] = aE[X] + b, \qquad E[X + Y] = E[X] + E[Y]$$

**大白话翻译：** 期望可以"拆开算"：每人工资翻倍再涨 500，平均也是翻倍再涨 500；两堆东西合起来的平均 = 各自平均之和。无论 $X$ 和 $Y$ 是否独立，第二个式子都成立。

**ML 为什么需要它：** 损失函数的定义就是期望——"模型在整个数据分布上的平均损失"。训练集有限，我们算的是样本平均，用它去**估计**期望（第五、六节会说为什么这样合法）。梯度下降优化的目标，本质就是在最小化一个期望。

**怎么用（代码）：**

```python
import numpy as np

# 掷骰子的期望
outcomes = np.array([1, 2, 3, 4, 5, 6])
probs = np.full(6, 1/6)          # 每个点数概率 1/6
expectation = np.sum(outcomes * probs)
print(f"骰子期望: {expectation}")  # 预期输出: 3.5

# 用模拟验证：掷 10 万次取平均
rng = np.random.default_rng(0)
rolls = rng.integers(1, 7, size=100_000)
print(f"模拟平均值: {rolls.mean():.4f}")  # 预期输出: 接近 3.5（如 3.4963）
```

### 3.3 方差与标准差【必须掌握】

**是什么（直觉）：** 期望告诉你"平均水平"，但不告诉你"波动大不大"。两个班平均分都是 75：A 班人人 73~77，B 班一半 50 一半 100。这两个班完全不同。**方差**（variance）衡量的就是"结果围绕期望上下波动的剧烈程度"。

$$\mathrm{Var}(X) = E\left[(X - E[X])^2\right]$$

**大白话翻译：** 对每个结果：先算它和平均值差多少（偏差），再平方（让正负偏差不抵消，且大偏差被惩罚得更狠），最后求期望（平均）。所以方差 = "偏差的平方的平均"。

**标准差**（standard deviation）就是方差开根号：$\sigma = \sqrt{\mathrm{Var}(X)}$。为什么开根号？因为方差的单位是原单位的平方（工资的方差单位是"元²"，莫名其妙），开根号后回到原单位，可以直接说"工资波动大约 ±3000 元"。

实用计算公式（编程和推导都常用）：

$$\mathrm{Var}(X) = E[X^2] - (E[X])^2$$

**大白话翻译：** 方差 = "平方的平均" 减去 "平均的平方"。不用先算均值再逐个算偏差，一趟数据流就能算出来。

**例子（掷骰子）：** $E[X^2] = (1+4+9+16+25+36)/6 = 91/6 \approx 15.17$，所以 $\mathrm{Var}(X) = 15.17 - 3.5^2 \approx 2.92$，标准差 $\approx 1.71$。

**ML 为什么需要它：**

- **特征标准化**：训练前把每个特征减去均值、除以标准差（z-score），让各特征波动范围一致，梯度下降才不会东倒西歪。
- **评估模型**：交叉验证多次得分的"均值 ± 标准差"，均值看水平，标准差看稳定性。
- **偏差-方差权衡**（bias-variance tradeoff）：模型欠拟合 = 偏差大（系统性学错方向），过拟合 = 方差大（对训练数据的随机波动反应过度）。这是 ML 诊断模型的核心框架。

**怎么用（代码）：**

```python
import numpy as np

scores_a = np.array([74, 75, 76, 75, 75])      # A 班：稳定
scores_b = np.array([50, 100, 50, 100, 75])    # B 班：两极分化

for name, s in [("A 班", scores_a), ("B 班", scores_b)]:
    print(f"{name}: 均值 {s.mean():.1f}, 标准差 {s.std():.2f}")
# 预期输出:
# A 班: 均值 75.0, 标准差 0.63
# B 班: 均值 75.0, 标准差 20.62
# 均值相同，标准差天差地别——只看平均会被骗
```

### 本节小结

1. 随机变量 = 给随机结果贴数字标签，让随机世界可以做算术；数据集的每一列都是随机变量。
2. 期望 = 按概率加权的平均 = 长期平均值；它对极端值敏感（工资例子的教训）。
3. 方差 = 偏差平方的平均，衡量波动大小；标准差是方差开根号，回到原单位。
4. 只看期望不看方差会被骗（两个平均分相同的班完全不同）。
5. ML 里的损失函数是期望，特征标准化、偏差-方差权衡都离不开期望和方差。

## 四、常见概率分布

**分布（distribution）** = 随机变量"取值 → 概率"的完整对照表。下面三个是 ML 最高频出场的。

### 4.1 伯努利分布【必须掌握】

**是什么（直觉）：** 只干一次、只有两种结果的试验：抛一次硬币、一个用户点不点广告、一张图是不是猫。结果用 1（成功/是）和 0（失败/否）表示，唯一的参数是成功概率 $p$：

$$P(X = 1) = p, \qquad P(X = 0) = 1 - p$$

可以合并写成一行：$P(X = x) = p^x (1-p)^{1-x}$，$x \in \{0, 1\}$。

**大白话翻译：** 当 $x=1$ 时，$(1-p)^{1-1} = (1-p)^0 = 1$，式子退化成 $p$；当 $x=0$ 时，$p^0 = 1$，式子退化成 $1-p$。一行公式两种情形自动切换——这个写法在第六节推导交叉熵时会用到，现在眼熟即可。

期望 $E[X] = p$，方差 $\mathrm{Var}(X) = p(1-p)$。**翻译：** 平均来看"成功比例就是 $p$"；$p$ 越接近 0.5 越捉摸不定（方差最大 0.25），$p$ 越接近 0 或 1 结果越确定（方差趋近 0）。

**ML 为什么需要它：** 所有**二分类**问题（垃圾邮件/正常、猫/狗、点击/不点击）的标签都服从伯努利分布。逻辑回归的输出层、sigmoid 函数，建模的就是伯努利分布的参数 $p$；交叉熵损失函数就是伯努利分布的极大似然（第六节揭晓）。

### 4.2 二项分布【暂时跳过（了解即可）】

**是什么（直觉）：** 把同一个伯努利试验独立重复 $n$ 次，数"成功了几次"。抛 10 次硬币，正面出现几次？$n$ 个用户里几个点了广告？这就是**二项分布**（binomial distribution），记作 $B(n, p)$：

$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$$

**大白话翻译：** 恰好成功 $k$ 次的概率 = 三件事相乘：$\binom{n}{k}$（读作"n 选 k"，从 $n$ 次里挑哪 $k$ 次成功，有多少种挑法）、$p^k$（这 $k$ 次都成功）、$(1-p)^{n-k}$（剩下 $n-k$ 次都失败）。

期望 $E[X] = np$（抛 100 次公平硬币，平均 50 次正面，符合直觉），方差 $\mathrm{Var}(X) = np(1-p)$。

**ML 为什么需要它：** A/B 测试的统计基础（"新按钮 1000 人里 52 人点击，比旧按钮好吗？"）；批量样本中类别数量的建模。你暂时不需要手算它，见到认识就行。

### 4.3 正态分布【必须掌握】

**是什么（直觉）：** 身高、体重、测量误差、考试分数（大样本）、流水线上零件的尺寸……世界上大量自然量的分布都长成同一条**钟形曲线**：中间高、两边低、左右对称。这就是**正态分布**（normal distribution，也叫高斯分布）。

它由两个参数完全决定：均值 $\mu$（钟的中心在哪）和标准差 $\sigma$（钟有多胖）。记作 $N(\mu, \sigma^2)$。

概率密度函数（连续型随机变量不直接给"某点的概率"，给的是"密度"，区间下的面积才是概率）：

$$f(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

**大白话翻译（别怕，逐个拆）：**

- $(x - \mu)^2$：$x$ 离中心 $\mu$ 有多远（平方后正负距离等价）；
- 除以 $2\sigma^2$：用波动大小做单位来衡量这个距离，钟越胖（$\sigma$ 大），同样距离显得越"不算远"；
- 外面套 $\exp(-\cdot)$：取负指数，让"离中心越远，密度越小"，而且衰减极快（指数级），这就是钟形两边急速下坠的原因；
- 前面的 $\frac{1}{\sqrt{2\pi}\sigma}$：归一化常数，作用只有一个——保证曲线下总面积 = 1（概率的规矩）。它的具体数值你一辈子都不用记。

**3σ 经验法则（必背）：** 对正态分布：

- 约 68% 的数据落在 $\mu \pm 1\sigma$ 内
- 约 95% 的数据落在 $\mu \pm 2\sigma$ 内
- 约 99.7% 的数据落在 $\mu \pm 3\sigma$ 内

**大白话翻译：** 离平均值超过 3 个标准差的事，一千次里只有约三次。所以"超出 3σ"常被当作**异常值**（outlier）的判据。比如服务器响应时间均值 100ms、标准差 10ms，突然来一个 200ms（超出 10σ），几乎肯定是出故障了。

**为什么正态分布在 ML 里无处不在：**

1. **中心极限定理**（第五节）：大量微小随机因素叠加，结果必然趋近正态。自然界的量大多是"很多因素叠加"的产物，所以遍地正态。
2. **噪声建模**：线性回归假设误差 $\varepsilon \sim N(0, \sigma^2)$，正是这个假设让 MSE 损失从极大似然里长出来（第六节）。
3. **初始化与正则化**：神经网络权重常用正态分布随机初始化；L2 正则化等价于假设权重服从正态先验。
4. **变分自编码器（VAE）、扩散模型**（图像生成、以及 LLM 相关的生成技术）：直接从标准正态分布里采样再一步步变成数据。

**怎么用（代码）：**

```python
import numpy as np

rng = np.random.default_rng(42)

# 从 N(100, 15^2) 采样：模拟"智商"一类的量
data = rng.normal(loc=100, scale=15, size=100_000)

print(f"均值: {data.mean():.2f}, 标准差: {data.std():.2f}")
# 预期输出: 均值约 100，标准差约 15

# 验证 3σ 经验法则
for k in (1, 2, 3):
    within = np.mean(np.abs(data - 100) <= k * 15)
    print(f"±{k}σ 内占比: {within:.1%}")
# 预期输出: 约 68.3%、95.4%、99.7%
```

**怎么用（异常检测直觉）：** 给一批数据算均值 $\mu$ 和标准差 $\sigma$，新数据若落在 $\mu \pm 3\sigma$ 之外，标记为可疑——这就是最简单的正态假设异常检测，工业界监控里天天在用。

### 本节小结

1. 伯努利分布：一次试验两种结果，参数只有 $p$；二分类标签的标配，sigmoid + 交叉熵的源头。【必须掌握】
2. 二项分布：$n$ 次伯努利试验数成功次数；A/B 测试的统计基础，见到认识即可。【暂时跳过】
3. 正态分布：钟形曲线，$\mu$ 定中心、$\sigma$ 定胖瘦；密度公式只需理解"离中心越远密度指数衰减"。【必须掌握】
4. 3σ 法则：68% / 95% / 99.7%；超出 3σ 可当异常值。
5. 正态无处不在的根因是中心极限定理；线性回归的高斯噪声假设、权重初始化、生成模型都离不开它。

## 五、大数定律与中心极限定理

### 5.1 大数定律【必须掌握（直觉版）】

**是什么（直觉）：** 抛硬币 10 次，可能 7 次正面（频率 0.7，离 0.5 很远）；抛 100 万次，频率几乎一定贴着 0.5。**大数定律**（Law of Large Numbers）说的就是：

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i \;\xrightarrow{n \to \infty}\; E[X]$$

**大白话翻译：** $\bar{X}_n$ 是 $n$ 次试验的样本平均；箭头表示"随着 $n$ 越来越大，它会越来越逼近"；右边是真实期望。一句话：**样本够多，样本平均就是真实期望。** 第一节的代码已经演示过了（10 次乱飘、10 万次贴死）。

**ML 为什么需要它：** 这是"用数据说话"的合法性根基。我们不知道"所有图片里猫图占多少"（真实期望），但我们有 5 万张标注图片（样本），大数定律保证：样本比例是真实比例的可靠估计。**整个 ML 的范式——"从有限训练集学到对无限新数据有效的规律"——都站在大数定律的肩膀上。** 训练集越大，这个估计越可靠，这就是"数据规模红利"的统计学解释。

### 5.2 中心极限定理【必须掌握（直觉版）】

**是什么（直觉）：** 大数定律说样本均值会逼近真值，但没回答"逼近得多快、误差长什么样"。**中心极限定理**（Central Limit Theorem, CLT）补上了这一刀，而且结论漂亮得惊人：

不管原始数据服从什么分布（均匀、指数、甚至歪七扭八），只要样本量 $n$ 够大，**样本均值 $\bar{X}_n$ 的分布就接近正态分布**：

$$\bar{X}_n \;\dot{\sim}\; N\left(\mu,\; \frac{\sigma^2}{n}\right)$$

**大白话翻译：** 不管单个人有多离谱，"一堆人的平均"都很正常（字面意义：正态）。样本均值的波动标准差是 $\sigma/\sqrt{n}$——注意 $n$ 在根号里：想让估计的精度提高 10 倍，样本量要增大 100 倍。这就是"数据越多收益递减"的定量原因。

**生活例子（烤肉店翻台）：** 单桌客人吃多久完全没准（15 分钟到 2 小时，分布很歪）。但今晚 60 桌的"平均用餐时长"会相当稳定，且多天统计下来，这个平均值会呈正态分布。个体不可预测，平均却高度可预测——这就是保险、民调、A/B 测试能做生意的原因。

**ML 为什么需要它：**

- **mini-batch 梯度下降**：用 256 个样本估计全体几百万样本的梯度，凭什么合法？因为梯度是平均值的函数，CLT 保证小样本平均的波动是可控的（且大致正态），噪声会随着 batch 增大按 $1/\sqrt{n}$ 缩小。
- **A/B 测试与模型评估**：比较两个模型的平均指标谁好，差异是否显著，靠的就是 CLT 给的正态近似。
- **解释正态分布的普遍性**：现实中的量多是无数微小因素之和，CLT 说"和（或平均）必趋近正态"，于是世界遍地钟形。

**怎么用（代码，亲眼见证奇迹）：**

```python
import numpy as np

rng = np.random.default_rng(42)

# 原始分布用指数分布——非常歪，和正态毫不沾边
population = rng.exponential(scale=2.0, size=1_000_000)
print(f"原始分布: 均值 {population.mean():.3f}, 标准差 {population.std():.3f}")
# 预期输出: 均值约 2.0，标准差约 2.0（指数分布两者相等）

# 每次抽 100 个取平均，重复 5000 次，看"样本均值"的分布
n = 100
sample_means = np.array([rng.choice(population, size=n).mean()
                         for _ in range(5000)])

print(f"样本均值: 均值 {sample_means.mean():.3f}, 标准差 {sample_means.std():.3f}")
# 预期输出: 均值仍约 2.0，但标准差约 2.0/sqrt(100) = 0.2
# 把 sample_means 画成直方图，会看到漂亮的钟形——尽管原始分布是歪的
```

### 本节小结

1. 大数定律：样本够多，样本平均 ≈ 真实期望。这是"从数据中学到规律"的全部合法性来源。【必须掌握】
2. 中心极限定理：不管原始分布多歪，样本均值的分布都趋近正态 $N(\mu, \sigma^2/n)$。【必须掌握】
3. 估计误差按 $1/\sqrt{n}$ 缩小：精度提 10 倍，数据要 100 倍。
4. mini-batch 梯度、A/B 测试、模型评估的统计根基都是 CLT。
5. CLT 同时解释了正态分布为什么在自然与工程中无处不在。

## 六、极大似然估计（MLE）

### 6.1 核心思想：什么参数最可能产生我们看到的数据【必须掌握】

**是什么（直觉）：** 你面前有一枚来路不明的硬币，不知道它正面向上的概率 $p$ 是多少。你抛了 10 次，结果是 7 正 3 反。现在问：$p$ 最可能是多少？

直觉答案：$p = 0.7$。这个直觉就是**极大似然估计**（Maximum Likelihood Estimation, MLE）：

> 把参数 $p$ 当作未知数，问"哪个 $p$ 让我们已经看到的这批数据出现的概率最大"，哪个最大就pick哪个。

**似然（likelihood）** 就是"给定参数时，观测数据出现的概率"。注意它和概率的区别：**概率是固定参数看数据，似然是固定数据看参数**——同一个函数，看的方向不同。这和贝叶斯里"正向/反向"的翻转一脉相承。

10 次抛掷 7 正 3 反（假设各次独立，概率可乘），似然函数：

$$L(p) = p^7 (1-p)^3$$

**大白话翻译：** 7 次正面每次贡献一个 $p$，3 次反面每次贡献一个 $(1-p)$，独立事件概率相乘。$L(p)$ 读作"当硬币正面概率为 $p$ 时，看到'7 正 3 反'这手数据的概率"。

接下来纯粹是"哪个 $p$ 让 $L(p)$ 最大"的优化问题。动手算（只需一点直觉，不必真求导）：$p=0.5$ 时 $L = 0.5^{10} \approx 0.00098$；$p=0.7$ 时 $L = 0.7^7 \times 0.3^3 \approx 0.00222$，明显更大；$p=0.9$ 时 $L \approx 0.00053$，又变小了。确实 $p=0.7$ 附近最大。

工程上有个标准技巧：一堆小于 1 的数相乘会迅速下溢成 0，而且乘法难优化，所以**取对数**，把乘法变加法（对数单调递增，不改变最大值的位置）：

$$\log L(p) = 7\log p + 3\log(1-p)$$

**大白话翻译：** $\log(ab) = \log a + \log b$，所以 $p^7(1-p)^3$ 取对数后变成两项相加。 maximizing $L$ 和 maximizing $\log L$ 是同一个答案。这个"对数似然"就是损失函数的真身。

一般结论（$n$ 次试验 $k$ 次成功）：$\hat{p} = \dfrac{k}{n}$。**翻译：** 最优估计就是"成功次数 ÷ 总次数"——频率本身就是 MLE，大数定律保证 $n$ 大时它就是真值。你的直觉和数学在终点会师了。

**怎么用（代码，网格搜索找最优 p）：**

```python
import numpy as np

# 观测数据：10 次抛掷，7 正 3 反
k, n = 7, 10

# 候选 p 从 0.01 到 0.99，挨个试
candidates = np.linspace(0.01, 0.99, 99)
log_likelihood = k * np.log(candidates) + (n - k) * np.log(1 - candidates)

best_p = candidates[np.argmax(log_likelihood)]
print(f"MLE 估计的 p: {best_p:.2f}")  # 预期输出: 0.70

# 理论解
print(f"理论解 k/n: {k/n:.2f}")        # 预期输出: 0.70
```

### 6.2 MLE 与损失函数：看穿 MSE 和交叉熵【必须掌握】

这是全文最关键的一段"思想链路"，请跟紧。

**训练模型的本质就是 MLE。** 模型的参数（权重 $w$）就是上文的 $p$；训练数据就是上文的"7 正 3 反"；训练 = 找一组 $w$，使得"这组 $w$ 下看到训练数据的概率（似然）最大"。所谓"损失函数"，就是**负的对数似然**——最大化对数似然 = 最小化负对数似然。ML 工程师说"最小化损失"，统计学家说"最大化似然"，是同一件事的两面。

**MSE（均方误差）从哪来：** 线性回归假设真实值 = 模型预测 + 噪声，且噪声服从正态分布 $N(0, \sigma^2)$：

$$y = wx + b + \varepsilon, \quad \varepsilon \sim N(0, \sigma^2)$$

把正态密度（4.3 节那个公式）代入似然、取对数、取负、丢掉与 $w$ 无关的常数，剩下的核心部分正是：

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

**大白话翻译：** $y_i$ 是真实值，$\hat{y}_i$ 是模型预测值，"差的平方求平均"就是 MSE。链条是：**假设误差是正态分布 → MLE → 自动长出"平方误差"。** 平方不是谁拍脑袋定的，它是正态分布密度里那个 $(x-\mu)^2$ 的直接后裔。（这也解释了 MSE 为什么怕异常值：正态分布假设"大误差极其罕见"，一旦出现大误差，平方项会拼命惩罚模型去迁就它。）

**交叉熵从哪来：** 逻辑回归假设标签服从伯努利分布（4.1 节），模型输出 $\hat{p}$ 是"为 1 的概率"。一个样本 $(x, y)$ 的似然按 4.1 的合并写法是 $\hat{p}^{y}(1-\hat{p})^{1-y}$。取对数取负：

$$-\left[ y \log \hat{p} + (1-y) \log(1-\hat{p}) \right]$$

**大白话翻译：** 真实标签 $y=1$ 时，只剩 $-\log \hat{p}$——模型对正确类别给的概率越大，损失越小；$y=0$ 时只剩 $-\log(1-\hat{p})$，同理。把$N$个样本加起来平均，就是**交叉熵损失**（也叫 log loss）。它不是什么神秘公式，就是"伯努利分布的负对数似然"。

多分类版本（Softmax 分类、LLM 的 next-token 预测）同理：假设标签服从"多类别版伯努利"（categorical 分布），MLE 推出的损失就是多类交叉熵：

$$-\sum_{c} y_c \log \hat{p}_c$$

**大白话翻译：** $y_c$ 是真实标签的 one-hot 编码（正确类别为 1，其余为 0），所以求和里其实只有正确类别那一项活着：$-\log \hat{p}_{\text{正确类别}}$。LLM 训练时，每个位置都在做这件事：让正确下一个词的概率尽量大。**你学的每一个 LLM，都是用这一个式子喂出来的。**

**信息汇总表（这张表建议背下来）：**

| 任务 | 对标签的概率假设 | MLE 推出的损失 |
|---|---|---|
| 回归（预测连续值） | 正态分布 | MSE（均方误差） |
| 二分类 | 伯努利分布 | 二元交叉熵 |
| 多分类 / LLM 下一个词 | 类别分布（Softmax 输出） | 多类交叉熵 |

### 本节小结

1. MLE 的灵魂问题："什么样的参数最可能产生我们看到的数据？"——固定数据、调参数、让似然最大。
2. 似然和概率是同一个函数的两个观察方向；取对数把连乘变连加，防止下溢且好优化。
3. 硬币例子：10 抛 7 正，MLE 给出 $\hat{p}=0.7$；一般结论 $\hat{p}=k/n$，频率即 MLE。
4. 训练模型 = 对参数做 MLE；损失函数 = 负对数似然。
5. 正态假设 → MSE；伯努利假设 → 交叉熵；Softmax 多分类和 LLM → 多类交叉熵。损失函数全是 MLE 的孩子。

## 七、信息论基础（为交叉熵打地基）

### 7.1 信息量 = 意外程度【必须掌握】

**是什么（直觉）：** 两句话，哪句"信息量大"？

- "明天太阳从东边升起"——废话，毫无信息量；
- "明天下雪"（假设你在海南）——惊人，信息量巨大。

可见**信息量衡量的是"意外程度"**：越不可能发生的事，一旦发生，带给你的信息越多。1930 年代香农（Shannon）把它定量化：

$$I(x) = -\log_2 p(x)$$

**大白话翻译：** $p(x)$ 是事件 $x$ 发生的概率。概率越小，$-\log$ 之后越大（意外程度越高）；必然事件 $p=1$ 的信息量是 $-\log 1 = 0$（废话不配拥有信息量）。单位叫**比特**（bit）。

为什么用对数？因为信息量该有"可加性"：两个独立事件同时发生，总信息量应该是各自相加。抛两次硬币都正面：$p = 0.5 \times 0.5 = 0.25$，$I = -\log_2 0.25 = 2$ bit，恰好是单次（1 bit）的两倍。概率相乘、信息量相加，对数正是"乘法变加法"的转换器。

以 2 为底时，一个 50/50 的事件（抛硬币）信息量恰好 1 bit——回答一个是非题，消除一半不确定性，这就是"比特"的原始含义。

### 7.2 熵 = 平均意外程度【必须掌握】

**是什么（直觉）：** 单个事件有信息量，一个**分布**（一整套事件及其概率）的"平均信息量"就叫**熵**（entropy）：

$$H(p) = -\sum_{i} p_i \log_2 p_i$$

**大白话翻译：** 对每个可能结果，用它的信息量 $-\log_2 p_i$ 乘以它的概率 $p_i$（意外的事不常发生，要按概率加权），全部加起来。所以熵 = "这个分布平均每次给我们多大的意外"，或者说"这个随机变量有多捉摸不定"。

**生活例子（天气 vs 抛硬币）：**

- 沙漠城市："明天晴天"概率 99%——基本没悬念，熵很低（约 0.08 bit）。
- 公平硬币：正反各 50%——最捉摸不定，熵 = 1 bit（最大值）。
- 抛 3 面骰子（均匀）：熵 = $\log_2 3 \approx 1.58$ bit——可能性越多越均匀，熵越大。

**核心规律：分布越均匀，熵越大；分布越确定（概率集中在一件事上），熵越小。** 熵是"不确定性"的度量。

**ML 为什么需要它：**

- **决策树的特征选择**：ID3/C4.5 算法用"信息增益"选分裂特征——按哪个特征切分后，数据的不确定性（熵）下降最多，就选哪个。你学习计划里"决策树"模块会迎面撞上它。
- **语言模型**：语言的熵衡量"下一个词有多难猜"。LLM 的进步史就是不断降低文本熵（perplexity，困惑度，就是熵的指数化）的历史。

**怎么用（代码）：**

```python
import numpy as np

def entropy(probs):
    probs = np.asarray(probs, dtype=float)
    probs = probs[probs > 0]              # 0*log(0) 约定为 0，先过滤
    return -np.sum(probs * np.log2(probs))

print(f"公平硬币: {entropy([0.5, 0.5]):.3f} bit")      # 预期输出: 1.000
print(f"作弊硬币(0.9正面): {entropy([0.9, 0.1]):.3f} bit")  # 预期输出: 约 0.469
print(f"沙漠天气(0.99晴): {entropy([0.99, 0.01]):.3f} bit") # 预期输出: 约 0.081
print(f"公平骰子: {entropy([1/6]*6):.3f} bit")          # 预期输出: 约 2.585
# 规律肉眼可见：越确定熵越小，越均匀/可能性越多熵越大
```

### 7.3 交叉熵：用错误分布描述真实分布的代价【必须掌握】

**是什么（直觉）：** 先建立一个画面：**编码**。你要给远方的战友发电报报告明天的天气，电报按 bit 计费。如果天气总是晴（分布很确定），你可以设计一套很省的编码：晴=0（1 bit），雨=10，雪=11。平均下来每封电报花的 bit 数，理论下限就是这个分布的**熵**——用自己的真实分布设计编码，代价就是熵，没有更省的方案。

但如果你**用错了分布**呢？你以为这里是沙漠（按 $q$ 分布设计编码：晴天编码很短），实际这里是梅雨江南（真实分布是 $p$：经常下雨）。结果晴天编码很短但几乎用不上，雨天编码很长却天天用——平均每封电报花的 bit 数必然超过真实熵。这个"用错误分布 $q$ 去编码真实分布 $p$ 的平均代价"，就是**交叉熵**（cross-entropy）：

$$H(p, q) = -\sum_{i} p_i \log_2 q_i$$

**大白话翻译：** 注意它和熵公式的区别：熵里是 $p_i \log p_i$（用自己的分布编码自己），交叉熵里是 $p_i \log q_i$——**真实发生的频率用 $p_i$（现实说了算），但编码长度按 $q_i$（模型的信念）来**。它衡量的正是"模型信念 $q$ 与现实 $p$ 不符"造成的平均代价。

铁律：$H(p, q) \ge H(p)$，等号只在 $q = p$ 时成立。**翻译：** 用任何错误的信念编码现实，代价必然更高；只有当模型的信念和现实完全一致时，代价降到最低（= 熵）。所以**最小化交叉熵 = 逼着模型的输出分布去贴近真实分布**——这就是训练分类器。

两者的差有专门的名字：**KL 散度**（相对熵）$D_{KL}(p \| q) = H(p, q) - H(p)$，衡量"分布 $q$ 和真实分布 $p$ 差多远"。训练时 $p$（数据）固定，最小化交叉熵和最小化 KL 散度等价。你在蒸馏（knowledge distillation，比如用小模型学大模型）、强化学习（RLHF 里限制策略不要偏离太远）里会反复见到 KL 散度。

**和逻辑回归 / Softmax 的联系（把第六节合上环）：**

分类问题里：真实分布 $p$ 就是标签的 one-hot 编码（正确类别概率 1，其余 0）；模型分布 $q$ 就是 Softmax 输出的概率向量。代入交叉熵：

$$H(p, q) = -\sum_c p_c \log q_c = -\log q_{\text{正确类别}}$$

**大白话翻译：** one-hot 里只有正确类别那一项是 1，其余全是 0，求和瞬间只剩一项：**交叉熵损失 = 模型给正确类别的概率取负对数**。模型对正确答案越自信（$q$ 越接近 1），损失越接近 0；越不自信，损失越大；如果模型给正确答案的概率是 0.01，损失高达 $-\log 0.01 \approx 4.6$（自然对数），重罚。

这正是第六节 MLE 推出的同一个式子——**交叉熵同时是"信息论里最省编码的代价"和"统计里伯努利/类别分布的最大似然"**，两条路通到同一扇门。至此，从信息量到熵到交叉熵再到损失函数，整个链条闭环了。

**怎么用（代码）：**

```python
import numpy as np

def cross_entropy(p, q, eps=1e-12):
    p, q = np.asarray(p, float), np.asarray(q, float)
    q = np.clip(q, eps, 1.0)   # 防止 log(0) 爆炸
    return -np.sum(p * np.log(q))   # 深度学习惯例用自然对数

# 三分类：真实是"猫"（one-hot）
p = [1.0, 0.0, 0.0]

q_good = [0.90, 0.05, 0.05]   # 模型 A：自信且正确
q_weak = [0.40, 0.35, 0.25]   # 模型 B：对但心虚
q_bad  = [0.05, 0.90, 0.05]   # 模型 C：自信地错

print(f"模型 A 损失: {cross_entropy(p, q_good):.3f}")  # 预期输出: 约 0.105
print(f"模型 B 损失: {cross_entropy(p, q_weak):.3f}")  # 预期输出: 约 0.916
print(f"模型 C 损失: {cross_entropy(p, q_bad):.3f}")  # 预期输出: 约 2.996
# 结论：越自信且正确损失越小；自信地错被重罚——这正是训练想要的信号
```

### 本节小结

1. 信息量 $-\log p$ = 意外程度：越不可能的事，发生时信息量越大；对数让乘法概率变成可加的信息。
2. 熵 = 分布的平均意外程度 = 不确定性度量：越均匀越大，越确定越小；决策树的信息增益、语言模型的困惑度都是它。
3. 交叉熵 $H(p,q)$ = 用模型的信念 $q$ 编码现实 $p$ 的平均代价；永远 ≥ 熵，只在 $q=p$ 时取到最小。
4. 分类任务中交叉熵退化为 $-\log q_{\text{正确类别}}$：对正确答案越自信损失越小，自信地错被重罚。
5. 交叉熵 = 信息论的最优编码代价 = MLE 的负对数似然。熵 → 交叉熵 → 损失函数，链条闭环。

## 自测题（附参考答案）

**1.** 某病患病率 0.5%，检测灵敏度 95%，假阳性率 5%。体检阳性的人真生病的概率大约是多少？（凭直觉先猜一个数，再算，比较两者）

> **参考答案：** 约 8.7%。$P(\text{病}|\text{阳}) = \dfrac{0.95 \times 0.005}{0.95 \times 0.005 + 0.05 \times 0.995} = \dfrac{0.00475}{0.0545} \approx 0.087$。大多数人直觉猜 90%+，这就是忽略先验的典型错误。

**2.** 两个投资方案期望收益相同，A 的方差远大于 B。哪个更"稳"？期望和方差分别告诉你什么？

> **参考答案：** B 更稳。期望告诉你"长期平均赚多少"，方差告诉你"实际结果围绕平均波动多剧烈"。期望相同、方差大意味着可能大赚也可能大亏；方差小意味着结果基本锁定在平均附近。

**3.** 为什么训练神经网络时可以用 256 个样本的 mini-batch 去估计全体训练集的梯度？依据哪两个定理？

> **参考答案：** 大数定律保证样本平均（batch 平均梯度）随样本量增大逼近真实期望（全量梯度）；中心极限定理保证这个估计的误差大致正态、且按 $1/\sqrt{n}$ 缩小——256 个样本的估计已经足够可靠，而计算量只有全量的零头。

**4.** 一枚硬币抛 20 次出现 15 次正面。用极大似然估计，$p$（正面概率）的估计值是多少？写出似然函数。

> **参考答案：** 似然 $L(p) = p^{15}(1-p)^{5}$，MLE 估计 $\hat{p} = 15/20 = 0.75$。注意：这不代表"硬币一定是歪的"（20 次样本太少，可能只是运气），MLE 只是回答"哪个 $p$ 最配得上这手数据"。

**5.** 模型对某个样本的 Softmax 输出是 [0.1, 0.7, 0.2]，正确类别是第 1 类（下标 0）。这个样本的交叉熵损失是多少（用自然对数）？如果模型把第 1 类的概率提高到 0.9，损失变成多少？

> **参考答案：** $-\ln 0.1 \approx 2.303$；提高到 0.9 后 $-\ln 0.9 \approx 0.105$。交叉熵只关心模型给"正确类别"的概率，其余类别不直接参与（它们通过 Softmax 归一化间接拉扯）。
