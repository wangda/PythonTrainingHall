## 一、函数：输入 → 输出的机器

### 1.1 函数是什么（直觉）

**必须掌握。**

把函数想象成一台自动售货机：

- 你投进去一个东西（**输入**，通常记作 $x$）；
- 机器按固定规则处理；
- 吐出来一个东西（**输出**，通常记作 $y$ 或 $f(x)$）。

写成数学式子就是：

$$y = f(x)$$

大白话翻译："$y$ 等于 $f$ 作用于 $x$"。$f$ 是机器的名字（function 的缩写），$x$ 是输入，$y$ 是输出。这条式子只表达一件事：**输入确定，输出就确定**。

程序员视角：函数就是你在 Python 里天天写的东西。

```python
def f(x):
    return 2 * x + 1

print(f(3))   # 输出 7：输入 3，机器规则是"乘 2 加 1"，吐出 7
print(f(10))  # 输出 21
```

数学里的 $f(x) = 2x + 1$ 和上面的 Python 函数是**一模一样的东西**，只是写法不同。

### 1.2 常见函数长什么样

**必须掌握。** 不需要背，但要做到"看到式子能大概想到曲线形状"。

**线性函数**（一条直线）：

$$f(x) = wx + b$$

大白话翻译：$x$ 是输入；$w$ 是一个固定的数，叫**斜率**，控制直线有多陡（$w$ 越大，$x$ 变一点 $y$ 就猛变）；$b$ 也是一个固定的数，叫**截距**，控制直线整体上下平移。$w$ 和 $b$ 就是以后模型里要"学习"的**参数**的雏形。

生活例子：出租车计费。$x$ 是公里数，$w$ 是每公里单价，$b$ 是起步价。

**二次函数**（一条抛物线，碗状或倒碗状）：

$$f(x) = x^2$$

大白话翻译：输出等于输入乘以它自己。$x=3$ 时输出 $9$，$x=-3$ 时输出也是 $9$（负数乘负数得正）。它的图像是一个开口向上的"碗"，碗底在 $x=0$ 处。

为什么重要：**损失函数常常长得像碗**。训练模型的目标就是找到碗底（损失最小的位置）。"找碗底"这件事，就是后面梯度下降要干的活。

**指数函数**（越涨越快的曲线）：

$$f(x) = e^x$$

大白话翻译：$e$ 是一个固定的数，约等于 $2.718$（和圆周率 $\pi$ 类似，是自然界里冒出来的常数，不用管它是怎么来的）。$e^x$ 就是把 $e$ 自己乘自己，一共乘 $x$ 次。$x$ 越大，它涨得越疯狂；$x$ 越小（负数），它越贴近 0 但永远大于 0。

生活例子：细菌繁殖、复利——"利滚利"就是指数增长。

为什么重要：softmax 函数（逻辑回归和多分类的核心）、注意力机制里的打分，都用 $e^x$ 把任意数字变成正数。

**对数函数**（指数函数的"反向操作"）：

$$f(x) = \ln(x)$$

大白话翻译：$\ln(x)$ 问的问题是："$e$ 的几次方等于 $x$？"比如 $\ln(e^3) = 3$，意思是"$e$ 的 3 次方等于 $e^3$"——废话，但这正是关键：**对数能把指数"拆"回原来的次数**。它和 $e^x$ 互为逆运算，就像"加 5"和"减 5"互相抵消。

为什么重要：交叉熵损失函数（逻辑回归、所有分类模型、LLM 的训练目标）里全是 $\ln$。它能把"概率连乘"变成"对数连加"，避免计算机里一堆小数相乘变成 0（这叫**数值下溢**）。

```python
import numpy as np

x = np.array([-2, -1, 0, 1, 2])

print(2 * x + 1)    # 线性：[-3 -1  1  3  5]，匀速增长
print(x ** 2)       # 二次：[4 1 0 1 4]，一个碗，碗底在 x=0
print(np.exp(x))    # 指数：[0.135 0.368 1.0 2.718 7.389]，越涨越快
print(np.log(np.exp(x)))  # 对数抵消指数：[-2. -1.  0.  1.  2.]，还原了！
```

预期输出说明：最后一行演示了 $\ln(e^x) = x$，对数和指数互相抵消，输入什么就吐出什么。

### 1.3 为什么模型就是函数

**必须掌握。这是整个 ML 的世界观。**

一句话：**机器学习里的"模型"，就是一个函数；训练模型，就是调整这个函数内部的参数，让它的输出尽量接近正确答案。**

- 线性回归：$f(x) = wx + b$，要学的就是 $w$ 和 $b$ 这两个数。
- 逻辑回归：$f(x) = \dfrac{1}{1 + e^{-(wx+b)}}$，在直线外面套一个 S 形函数，把输出压到 0~1 之间当概率用。
- 神经网络 / LLM：依然是函数，只是 $f$ 里面套了成千上万层，参数从 2 个变成几千亿个。GPT 的"思考"，本质上就是对输入的文字做一个超级复杂的函数计算。

所以后面所有的数学，都是在回答一个问题：**怎么调整函数里的参数，让输出更准？**

### 本节小结

- 函数 = 输入 → 输出的机器，$y = f(x)$，和 Python 函数是同一个东西。
- 线性、二次、指数、对数四种函数要认得出形状：直线、碗、疯涨曲线、指数的逆操作。
- 模型就是函数，训练就是调参数。这是整个 ML 的底层世界观。
- $\ln$ 和 $e^x$ 互相抵消，这一点在损失函数里会反复用到。

## 二、变化率与导数：车速表直觉

### 2.1 导数是什么（直觉）

**必须掌握。**

想象你在开车：

- 仪表盘上的**里程表**显示你一共开了多远（这是"位置"，相当于函数值 $f(x)$）。
- **车速表**显示你此刻开多快（这是"位置变化的快慢"，相当于**导数**）。

导数回答的问题就是：**输入 $x$ 变一点点，输出 $y$ 会变多少、变多快？**

- 车速表读数为 0：车停着，位置不变 → 导数为 0，函数在这个点不增不减。
- 车速表读数很大：位置飞速变化 → 导数很大，函数在这个点变化剧烈。
- 倒车（速度为负）：位置在减少 → 导数为负，函数在下降。

几何上，导数还有一张脸：**曲线上某一点的切线斜率**。

斜率这个词你初中学过：直线的斜率 = 上升高度 ÷ 水平距离（"爬升 ÷ 前进"）。曲线每一小段的陡峭程度不同，导数就是**在某一 precise 的点上，曲线的陡峭程度**。

记号（看到别慌，都是同一个意思）：

$$f'(x) \quad \text{或} \quad \frac{dy}{dx}$$

大白话翻译：$f'(x)$ 读作"$f$ 撇 $x$"，就是"$f$ 在 $x$ 这一点的导数（变化率）"。$\frac{dy}{dx}$ 读作"$dy$ 比 $dx$"：$dx$ 表示"$x$ 变了一丁点"，$dy$ 表示"随之 $y$ 变了一丁点"，整个分数就是"$y$ 的变化量 ÷ $x$ 的变化量"——正是"爬升 ÷ 前进"那个斜率的极限版本。$d$ 你就理解成"一丁点变化"的意思。

### 2.2 常见函数的导数（查表就行，不用背推导）

**必须掌握用法，推导过程暂时跳过。**

数学家有办法从定义严格推出每个函数的导数，过程我们不管（"暂时跳过"），直接给结论表：

| 函数 $f(x)$ | 导数 $f'(x)$ | 大白话 |
|---|---|---|
| $c$（常数，如 5） | $0$ | 不动的量，变化率为 0 |
| $x$ | $1$ | $x$ 变 1，$y$ 也变 1，斜率恒为 1 |
| $x^2$ | $2x$ | 越靠右越陡，$x=0$ 处水平（碗底！） |
| $x^n$ | $n \cdot x^{n-1}$ | 幂函数通用规则：指数搬下来当系数，指数减 1 |
| $e^x$ | $e^x$ | 最神奇的一个：导数等于它自己 |
| $\ln(x)$ | $\frac{1}{x}$ | $x$ 越大涨得越慢 |

怎么用这张表？看例子：

例 1：$f(x) = x^2$，问 $x = 3$ 这一点函数变化多快？

- 查表：导数是 $f'(x) = 2x$。
- 代入：$f'(3) = 2 \times 3 = 6$。
- 含义：在 $x=3$ 附近，$x$ 每增加一丁点（比如 0.001），$y$ 大约增加它的 6 倍（0.006）。

例 2：$f(x) = x^2$ 的"碗底"在哪？

- 碗底就是曲线水平（不升不降）的位置，即导数为 0 的位置。
- 令 $2x = 0$，解得 $x = 0$。
- **这就是优化思想的雏形：导数为 0 的地方，往往就是最小值/最大值所在的地方。**训练模型找"损失最小的参数"，用的就是这个思想（只是参数多了之后不能精确求解，只能一步步逼近——见第四节梯度下降）。

### 2.3 用代码"亲手摸一下"导数

不写数学推导，用 Python 数值验证"$x$ 变一丁点，$y$ 变几倍"：

```python
import numpy as np

def f(x):
    return x ** 2

x = 3.0
dx = 0.0001                      # "一丁点"变化

slope = (f(x + dx) - f(x)) / dx  # 爬升 ÷ 前进
print(slope)                     # 输出约 6.0001，非常接近理论值 2x = 6

x0 = 0.0
slope0 = (f(x0 + dx) - f(x0)) / dx
print(slope0)                    # 输出约 0.0001，非常接近 0 —— 碗底是水平的
```

预期输出说明：第一行约 6.0，第二行约 0.0。这就是导数的数值版定义：**让 $x$ 挪动一丁点，看看 $y$ 跟着挪了几倍**。深度学习框架（PyTorch）帮我们自动算导数，但背后干的就是这类事，只是算得更聪明、更精确。

### 2.4 为什么 ML 需要导数

**必须理解的一句话：导数告诉我们"参数往哪个方向调、调多少，损失会变小"。**

回到出租车的例子：$f(x) = wx + b$。假设真实的 $w$ 应该是 2（每公里 2 元），但模型当前猜的是 $w = 5$，预测就偏贵，**损失**（预测与真实的差距）就大。

损失是关于 $w$ 的函数。我们想知道：把 $w$ 调小一点，损失会变小还是变大？——这正是"损失对 $w$ 的导数"回答的问题。导数为正，说明 $w$ 增大损失也增大（该往小调）；导数为负，说明该往大调。

线性回归、逻辑回归、神经网络的训练，全是这一个动作的循环：**算导数 → 按导数指示的方向微调参数 → 再算 → 再调**。

### 本节小结

- 导数 = 变化率 = 车速表 = 曲线某点的陡峭程度（切线斜率）。
- 记号 $f'(x)$ 和 $\frac{dy}{dx}$ 是同一个东西，$d$ 表示"一丁点变化"。
- 常见函数的导数会查表会用即可：$(x^n)' = nx^{n-1}$，$(e^x)' = e^x$，$(\ln x)' = 1/x$。
- 导数为 0 的地方常常是最大/最小值——这是"找碗底"的钥匙。
- ML 里，"损失对参数的导数"指导参数该怎么调，这是训练的原子动作。

## 三、导数的运算法则：重点是链式法则

### 3.1 加减乘法则（了解即可）

**加减法则：必须掌握（很简单）。乘法法则：暂时跳过细节，知道有这回事。**

**加减法则**：两个函数相加减，导数就是各自导数相加减。

$$\frac{d}{dx}[f(x) + g(x)] = f'(x) + g'(x)$$

大白话翻译：$\frac{d}{dx}$ 意思是"对 $x$ 求导"。整条式子说：两台机器并联（输出相加），总变化率 = 各自变化率相加。就像你和队友一起搬砖，团队速度 = 你的速度 + 他的速度。

例子：$f(x) = x^2 + x$，则 $f'(x) = 2x + 1$（$x^2$ 的导数 $2x$，加上 $x$ 的导数 $1$）。

**乘法法则**（暂时跳过，列出来混个脸熟）：

$$\frac{d}{dx}[f(x) \cdot g(x)] = f'(x) \cdot g(x) + f(x) \cdot g'(x)$$

大白话翻译：两个函数相乘时，"轮流求导再相加"——第一个求导乘第二个原样，加上第一个原样乘第二个求导。ML 里很少需要手动用它，框架会自动处理。

### 3.2 链式法则：反向传播的全部核心

**必须掌握。这是本文最重要的一节，没有之一。**

**先说什么叫"复合函数"（函数套函数）。** 一台机器的输出，直接喂给下一台机器当输入：

$$y = f(g(x))$$

大白话翻译：$x$ 先进机器 $g$，得到 $g(x)$；$g(x)$ 再进机器 $f$，得到最终输出 $y$。就像流水线：原料 → 粗加工 → 精加工 → 成品。

具体例子：$y = (2x + 1)^2$。这里 $g(x) = 2x + 1$（先乘 2 加 1），$f(u) = u^2$（再平方）。注意：数学家习惯给中间结果起个新名字 $u$，只是为了说起来方便。

**链式法则**说的是：求复合函数的变化率，就把每一层的变化率**乘起来**：

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$$

大白话翻译：$\frac{du}{dx}$ 是"第一层机器：$x$ 变一点，中间结果 $u$ 变多少"；$\frac{dy}{du}$ 是"第二层机器：$u$ 变一点，最终结果 $y$ 变多少"。两者一乘，就是"$x$ 变一点，最终结果 $y$ 变多少"。中间的那个 $du$ 一上一下"约掉"了，所以叫"链式"——像链条一样一环扣一环。

**洋葱剥皮类比**：复合函数像一颗洋葱，一层套一层。求导就是从外往里，每剥一层，乘上这一层的变化率。剥完所有层，把各层的变化率全乘起来，就得到最深处 $x$ 对最外层 $y$ 的影响。

**动手算一遍**（$y = (2x+1)^2$，求 $x = 1$ 时的导数）：

1. 拆层：$u = 2x + 1$（内层），$y = u^2$（外层）。
2. 各层求导：$\frac{du}{dx} = 2$（查表：$x$ 的导数是 1，系数 2 保留）；$\frac{dy}{du} = 2u$（查表：$u^2$ 的导数是 $2u$）。
3. 乘起来：$\frac{dy}{dx} = 2u \times 2 = 4u$。
4. 把 $u$ 换回 $x$：$u = 2x+1$，所以 $\frac{dy}{dx} = 4(2x+1)$。
5. 代入 $x = 1$：$4 \times 3 = 12$。

含义：在 $x=1$ 附近，$x$ 每变 1 丁点，$y$ 大约变它的 12 倍。

**代码验证**（不手算，让计算机告诉我们答案）：

```python
import numpy as np

def f(x):
    return (2 * x + 1) ** 2   # y = (2x+1)^2

x = 1.0
dx = 0.0001
slope = (f(x + dx) - f(x)) / dx
print(slope)   # 输出约 12.0004，非常接近我们手算的 12
```

预期输出说明：约 12，证明链式法则手算结果正确。

### 3.3 为什么链式法则 = 反向传播

**必须理解。**

神经网络的形状就是一颗巨型洋葱：

$$\text{输入} \rightarrow \text{第1层} \rightarrow \text{第2层} \rightarrow \cdots \rightarrow \text{第100层} \rightarrow \text{预测} \rightarrow \text{损失}$$

每一层都是一台小机器（函数），上百层套在一起。训练时我们要问："第 1 层的某个参数变一点，最终的损失变多少？"——这个参数离损失隔着 100 层，怎么办？

链式法则说：把从损失到该参数路径上**每一层的局部变化率全部乘起来**就行。实际计算是从损失这头（最外层）往回走，一层一层把导数"传"回去——所以这个算法叫**反向传播（backpropagation）**。

- PyTorch 里的 `loss.backward()`，干的就是这件事：从 loss 出发，沿链式法则把所有参数的导数算出来。
- **梯度消失/爆炸**：后面会学到的名词。既然链式法则是把几十上百个数**连乘**，如果每个数都小于 1，乘到后来就趋近于 0（梯度消失，前面几层学不到东西）；如果每个数都大于 1，乘到后来就爆炸成天文数字（梯度爆炸）。LSTM、ResNet、各种归一化技术，很大程度上都是在解决这个连乘失控的问题。

一句话记住：**反向传播没有新数学，它就是链式法则的批量、自动化执行。**

### 本节小结

- 加减法则：分别求导再相加。乘法法则暂时跳过。
- 链式法则：函数套函数时，把每一层的导数乘起来，$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$。
- 洋葱剥皮：从外到内逐层求导、逐层相乘。
- 反向传播 = 链式法则在多层网络上的自动执行，`loss.backward()` 背后就是它。
- 梯度消失/爆炸的根源是"多层导数连乘失控"。

## 四、多元函数、偏导数与梯度：下山找碗底

### 4.1 多元函数与偏导数

**必须掌握。**

前面的函数只有一个输入 $x$。但真实模型有成千上万个参数——哪怕最简单的线性回归也有 $w$ 和 $b$ 两个。输入不止一个的函数叫**多元函数**：

$$L(w, b) = (wx + b - y_{真实})^2$$

大白话翻译：$L$ 是损失（Loss），它同时取决于两个旋钮 $w$ 和 $b$。$wx + b$ 是模型的预测值，$y_{真实}$ 是正确答案，两者相减是误差，平方一下让误差永远为正（正负误差不会互相抵消）。这条式子就是线性回归最常用的**均方误差损失**的单个样本版本。

**烤肉类比**：烤肉的火候取决于"温度"和"时间"两个旋钮。想知道温度该怎么调，就**固定时间不动**，只拧温度，看肉的变化；想知道时间该怎么调，就固定温度，只拧时间。**一次只研究一个变量，其余全部当成固定常数**——这就是**偏导数**的思想。

记号：

$$\frac{\partial L}{\partial w}$$

大白话翻译：$\partial$ 是字母 $d$ 的"圆体写法"，读作"偏"。整个符号读作"$L$ 对 $w$ 的偏导数"，意思是：**只让 $w$ 动一丁点（其他变量全部当常数钉死），$L$ 会变多少**。

**求偏导的唯一技巧：把其他变量当常数，然后照旧的导数表求导。**

例子：$L(w, b) = w^2 + 3wb + b^2$，求 $\frac{\partial L}{\partial w}$。

- 把 $b$ 当成一个固定数字（比如当成 5 那样的死数）。
- $w^2$ 对 $w$ 求导得 $2w$。
- $3wb$ 对 $w$ 求导：$3b$ 是常数系数，$w$ 的导数是 1，所以得 $3b$。
- $b^2$ 里没有 $w$，整个是常数，导数为 0。
- 合起来：$\frac{\partial L}{\partial w} = 2w + 3b$。

```python
import numpy as np

def loss(w, b):
    return w ** 2 + 3 * w * b + b ** 2

w, b = 1.0, 2.0
dw = 0.0001

# 数值验证：只动 w，b 钉死不动
partial_w = (loss(w + dw, b) - loss(w, b)) / dw
print(partial_w)        # 约 8.0；手算 2w + 3b = 2*1 + 3*2 = 8，对上了！
```

预期输出说明：约 8.0。注意代码里 `loss(w + dw, b)` 只有第一个参数动了，这就是"偏"字的含义。

### 4.2 梯度：最陡上坡方向

**必须掌握。**

每个参数都能算出一个偏导数。把所有偏导数**排成一个向量**（就是一串数字），得到的东西叫**梯度**，记作 $\nabla L$：

$$\nabla L = \left( \frac{\partial L}{\partial w},\ \frac{\partial L}{\partial b} \right)$$

大白话翻译：$\nabla$ 这个倒三角读作"nabla"，看到它就直接念"梯度"即可。式子说：梯度就是把"$L$ 对每个参数的偏导数"挨个算出来，装进一个列表。参数有 1000 亿个（LLM），梯度就是 1000 亿个数排成的长队。

**梯度最重要的性质：它指向"函数值上升最快"的方向，即最陡上坡方向。**

**爬山类比**：你站在山上，浓雾弥漫，看不清全貌，只能用脚感受脚下的坡度。你想登顶（让 $L$ 最大）：

- 用脚尖试探四周，找到**最陡的上坡方向**——这就是梯度 $\nabla L$ 指的方向。
- 朝那个方向迈一步，海拔上升最快。

反过来，如果你想下山（让 $L$ 最小），就往**梯度的反方向**（$-\nabla L$）走，那是**最陡下坡方向**。

注意梯度的"方向"不是东南西北，而是"参数空间里每个参数该增还是该减"的组合。两个参数时，梯度 $(\frac{\partial L}{\partial w}, \frac{\partial L}{\partial b}) = (8, ?)$ 的意思是：增大 $w$ 会让 $L$ 快速上升（斜率 8 很大），所以想降 $L$ 就该减小 $w$，而且 $w$ 的调整"优先级"高。

### 4.3 梯度下降：所有神经网络训练的发动机

**必须掌握。这是全文最重要的一段。**

把上面所有零件组装起来。我们的目标：调整参数，让损失 $L$ 最小（找碗底）。方法：

1. 算出当前位置的梯度（每个参数的偏导数）。
2. 沿梯度的**反方向**（下坡方向）走一小步。
3. 到了新位置，重复 1、2，直到走到谷底（梯度接近 0，前后左右都是平的）。

数学写法（这是 ML 里出现频率最高的公式，值得背下来）：

$$w \leftarrow w - \eta \cdot \frac{\partial L}{\partial w}$$

大白话翻译：$\leftarrow$ 是"赋值"，意思是"用右边算出的新值替换掉 $w$ 的旧值"，跟 Python 的 `w = w - ...` 一模一样。$\eta$ 是希腊字母，读作"eta"，它就是大名鼎鼎的**学习率（learning rate）**——步子的大小。整条式子说：**新参数 = 旧参数 − 学习率 × 偏导数**。减去偏导数 = 沿最陡下坡方向走；乘以学习率 = 控制每步别迈太大。

**学习率的直觉**：

- 步子太大（$\eta$ 太大）：下山时一步跨过谷底，在两边山坡上反复横跳，甚至越跳越高（**不收敛/发散**）。
- 步子太小（$\eta$ 太小）：走得稳但慢如蜗牛，训练几万年也到不了谷底。
- 调学习率是训练模型的日常手艺活，你会在学习路径的每一个模块里反复见到它。

**完整代码示例**（用梯度下降找 $f(x) = x^2$ 的碗底，全程不查公式，只靠数值导数）：

```python
import numpy as np

def f(x):
    return x ** 2

def numerical_grad(x, h=1e-4):
    return (f(x + h) - f(x - h)) / (2 * h)   # 用左右各探一点，更准

x = 5.0          # 随机起点：站在 x=5 的山坡上
lr = 0.1         # 学习率：每步迈多大

for step in range(20):
    grad = numerical_grad(x)   # 1. 算梯度（当前位置的坡度）
    x = x - lr * grad          # 2. 沿下坡方向走一步
    print(f"第 {step+1:2d} 步: x = {x:.4f}, f(x) = {f(x):.6f}")

# 预期输出：x 从 5.0 一路缩小到接近 0（碗底），f(x) 趋近 0
# 第 1 步: x = 4.0000, ...
# 第 2 步: x = 3.2000, ...
# ...
# 第20 步: x = 0.0067, f(x) = 0.000045
```

预期输出说明：每一步 $x$ 都在向 0（碗底）靠近，且越靠近碗底步子自动越小（因为坡度变缓，梯度变小）——这正是"到谷底就停下"的天然机制。

把上面代码里的 $x$ 换成几百万个参数、把 $f$ 换成损失函数，就是**训练神经网络的全部核心循环**。你之后学的 SGD、Adam 等优化器，都只是在这个循环上改进"步子怎么迈得更聪明"。

### 本节小结

- 多元函数 = 多个输入旋钮的函数；偏导数 = 一次只动一个旋钮、其余钉死，看输出的变化。
- 梯度 $\nabla L$ = 所有偏导数排成的向量，指向"最陡上坡方向"；反方向就是最陡下坡。
- 梯度下降：反复执行 `参数 = 参数 − 学习率 × 偏导数`，一路走到谷底。
- 学习率控制步长：太大震荡发散，太小慢得要死。
- 这是所有神经网络（包括 LLM）训练的发动机，反向传播负责"高效算出梯度"，梯度下降负责"用梯度更新参数"。

## 五、（简单了解）泰勒展开与积分

> 这两块在 ML 里**极少直接手动使用**，属于"知道是干什么的即可"。全部标注：**暂时跳过细节**。学有余力再回来看。

### 5.1 泰勒展开：用简单函数近似复杂函数

**暂时跳过细节，只需记住一句话。**

一句话直觉：**任何光滑的复杂曲线，在某个点附近，都可以用一条直线（或抛物线、或更高次的多项式）去近似它，离该点越近越准。**

$$f(x) \approx f(a) + f'(a)(x - a)$$

大白话翻译：想在 $a$ 点附近猜 $f(x)$ 的值？用"$a$ 点的函数值"加上"$a$ 点的斜率 × 距离"就行——这其实是**用 $a$ 点的切线代替曲线本身**。项加得越多（再补 $x^2$ 项、$x^3$ 项……），近似越精确。

为什么 ML 需要它（了解即可）：

- 它是"梯度下降为什么有效"的理论地基：梯度下降本质上就是在当前位置用**切线（一阶泰勒展开）近似损失函数**，然后沿切线的下坡方向走一步。Adam 等二阶优化器则会用到抛物线（二阶）信息。
- 以后读论文遇到"Taylor approximation"不至于陌生。

### 5.2 积分：导数的逆运算，累积求和

**暂时跳过细节，只需记住一句话。**

一句话直觉：**积分就是"把无穷多个小薄片加起来"，求的是曲线下方的总面积**；它是导数的逆运算（导数把"总量"拆成"变化率"，积分把"变化率"累回"总量"）。

$$\int_a^b f(x)\,dx$$

大白话翻译：$\int$ 是拉长的 S，表示"Sum（求和）"；$a$ 到 $b$ 是求和的范围；$f(x)\,dx$ 表示"高度为 $f(x)$、宽度为一丁点 $dx$ 的细条面积"。整条式子：把 $x$ 从 $a$ 到 $b$ 之间所有细条的面积加起来。

程序员的秒懂版：积分就是一个连续的 `for` 循环累加。

```python
import numpy as np

def f(x):
    return x ** 2

# 用数值方法（黎曼和）近似 ∫₀¹ x² dx，理论答案是 1/3 ≈ 0.3333
xs = np.linspace(0, 1, 10001)
dx = xs[1] - xs[0]
area = np.sum(f(xs) * dx)
print(area)   # 输出约 0.3334，非常接近 1/3
```

预期输出说明：约 0.333，即曲线 $x^2$ 在 0 到 1 之间的面积。

为什么 ML 需要它（了解即可）：

- 概率论里，"连续随机变量落在某区间的概率"就是概率密度函数的积分（你接下来学概率统计时会碰面）。
- 期望、交叉熵的理论定义里有积分号。但**实践中**全部用离散求和代替（就像上面的代码），所以看到 $\int$ 时脑子里翻译成"求和 $\sum$"即可过关。

### 本节小结

- 泰勒展开：用简单的多项式（切线、抛物线）在局部近似复杂函数。梯度下降的合法性来自它。暂时跳过细节。
- 积分：连续版的累加，求曲线下面积，是导数的逆运算。实践中全用离散求和替代。暂时跳过细节。
- 这两个概念以后在论文里见到不慌即可，动手训练模型几乎用不到手算。

## 自测题

**题目**

1. 用一句话说明：为什么"模型就是函数"？训练模型到底在训练什么？
2. 函数 $f(x) = x^3$。查导数表，写出 $f'(x)$，并计算 $x = 2$ 时的导数值。这个数值的含义是什么？
3. 设 $y = (3x + 2)^2$。用链式法则求 $\frac{dy}{dx}$（写出拆层、各层导数、相乘三步）。
4. 损失 $L(w, b) = w^2 + 4b$。求 $\frac{\partial L}{\partial w}$ 和 $\frac{\partial L}{\partial b}$。当前 $w = 3, b = 1$，学习率 $\eta = 0.1$，按梯度下降公式更新一次，新的 $w$ 和 $b$ 各是多少？
5. 解释"梯度消失"：为什么层数很多的网络，靠近输入的层可能学不到东西？

**参考答案**

1. 模型接收输入（如一张图、一句话）并产出输出（如类别、下一个词），本质是一个从输入到输出的函数 $f$。训练就是调整 $f$ 内部的参数（$w$、$b$ 等），使输出尽量接近真实答案（损失最小）。
2. 查表 $(x^n)' = nx^{n-1}$，得 $f'(x) = 3x^2$。$f'(2) = 3 \times 4 = 12$。含义：在 $x = 2$ 附近，$x$ 每增加一丁点，$f(x)$ 大约增加它的 12 倍（该点切线斜率为 12）。
3. 拆层：$u = 3x + 2$，$y = u^2$。各层导数：$\frac{du}{dx} = 3$，$\frac{dy}{du} = 2u$。相乘：$\frac{dy}{dx} = 2u \cdot 3 = 6(3x + 2)$。
4. $\frac{\partial L}{\partial w} = 2w$（$4b$ 对 $w$ 是常数，导数为 0）；$\frac{\partial L}{\partial b} = 4$。更新：$w \leftarrow 3 - 0.1 \times (2 \times 3) = 3 - 0.6 = 2.4$；$b \leftarrow 1 - 0.1 \times 4 = 0.6$。
5. 反向传播靠链式法则把从损失到某一层路径上所有层的局部导数**连乘**。层数很多时，如果这些局部导数大多小于 1（例如常见激活函数的导数），连乘结果会指数级缩小趋近于 0，导致靠近输入的层收到的梯度几乎为 0，参数几乎不更新，于是"学不到东西"。
