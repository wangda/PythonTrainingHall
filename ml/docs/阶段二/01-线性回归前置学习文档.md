## 1. 什么是线性回归 🟢

### 1.1 是什么（直觉）

先造数据（后面所有章节都用它）：

```python
import numpy as np

rng = np.random.default_rng(42)          # 固定 seed，结果可复现
n = 50                                    # 50 套房子
area = rng.uniform(40, 160, n)                    # 面积：40~160 平米
price = 1.5 * area + 30 + rng.normal(0, 10, n)    # 价格（万）：真实规律 + 噪声
print(area[:5].round(1))    # [132.9  92.7 143.  123.7  51.3]
print(price[:5].round(1))   # [236.1 169.7 247.4 221.8  92.4]
```

把这 50 个点画在图上（x 轴面积，y 轴价格），你会看到它们大致沿一条直线分布。所谓**线性回归**，就是找一条直线 `y = wx + b`，让它"总体上离所有点最近"。

**关键认识：`y = wx + b` 就是你初中学的一次函数**（初中写作 `y = kx + b`，机器学习习惯把斜率叫 w、截距叫 b）。唯一的新问题是：初中老师直接告诉你 k 和 b，现在只有一堆散点，**w 和 b 要从数据里"学"出来**。这个"学"，就是本节三个角色要干的事。

### 1.2 为什么需要

预测是机器学习最古老也最实用的任务：房价、销量、气温、股价……只要"输入一个或几个数字，输出一个连续数字"，就是**回归**问题（输出是类别的叫分类，阶段二下一个模块的逻辑回归就是）。线性回归是所有回归方法的起点，也是后面神经网络的地基——**一个神经元做的事情本质上就是 `w·x + b` 再套一个非线性函数**。

### 1.3 怎么用：机器学习的三个角色

任何一个"监督学习"问题都拆成三个角色，线性回归是认识它们的最佳样本：

| 角色                              | 是什么                                         | 线性回归里具体是                           | 本文哪节 |
| --------------------------------- | ---------------------------------------------- | ------------------------------------------ | -------- |
| **<mark>模型（假设函数）</mark>** | 猜答案的公式，里面有待定的参数                 | `ŷ = wx + b`，参数是 w 和 b                | §1       |
| <mark>**损失函数**</mark>         | 衡量"猜得有多离谱"的尺子，输出一个数，越小越好 | MSE（均方误差）                            | §2       |
| **<mark>优化算法</mark>**         | 调整参数、让损失变小的方法                     | 闭式解（一步算出来）或梯度下降（一步步挪） | §3、§4   |

**"训练模型" = 用优化算法，找到让损失函数最小的那组参数。** 这句话在后面所有模块（逻辑回归、神经网络）一字不改地复用。

### 1.4 多特征：从一次函数到向量点积

只有面积一个特征时模型是 `ŷ = wx + b`。真实房价还取决于房龄、楼层、距地铁距离……每个特征配一个参数：

```
ŷ = w₁x₁ + w₂x₂ + w₃x₃ + b
```

**大白话翻译**：`x₁` 是面积、`x₂` 是房龄……每个特征乘上自己的"权重"（这个特征值多少钱），加起来再加个底价 b。

对照线性代数文档（`../阶段一/00-线性代数前置知识.md` 的点积一节）：`w₁x₁ + w₂x₂ + w₃x₃` 正是向量 **w** = (w₁, w₂, w₃) 和 **x** = (x₁, x₂, x₃) 的**点积**。所以模型写成：

```
ŷ = w · x + b
```

代码里就是 `X @ w + b`（`X` 是 `(n样本, n特征)` 的矩阵，一行是一套房子）。**为什么这很重要**：一次函数只是"一条直线"，向量点积版本是"高维空间里的一个平面"，但所有数学形式完全统一——学会一维的，多维白送。

**本节小结**：线性回归 = 从数据里学出一次函数（多特征时是点积 `w·x + b`）的参数 w、b。训练三角色：模型（猜答案的公式）、损失函数（错得多离谱）、优化算法（怎么调参数）。

### 1.5 "线性"的准确含义：对参数线性 🟢

初学者最容易误会的一句话，单独用一节讲透。**"线性回归"的"线性"不是说 y 和 x 画出来是直线，而是说模型对参数 w、b 是线性的。**

**什么叫"对参数线性"？** 把式子里所有的参数（w、b）圈出来，逐个检查姿态：每个参数都只是**一次方、光着身子乘以一个已知的东西（数或特征）、再相加**。满足这一点，就是线性回归——至于数据那一侧出现什么（x²、x³、sin(x)），图像弯成什么样，都无所谓。

**三步判断法**：

1. 把式子里所有的 w、b 圈出来；
2. 逐个检查：它是不是光着身子站在那儿（最多乘了一个已知量）？
3. 有没有任何一个参数被关进了函数里（sin、平方、指数），或者参数之间互相相乘？

全部光着身子 → 对参数线性 → 线性回归。有一个被关起来 → 不是。

**用例子过一遍**：

| 式子                     | 检查参数姿态                                | 是不是线性回归       |
| ------------------------ | ------------------------------------------- | -------------------- |
| `ŷ = wx + b`             | w、b 都光着身子                             | ✅ 是                 |
| `ŷ = w₁x₁ + w₂x₂ + b`    | 特征再多，参数照样光着身子                  | ✅ 是                 |
| `ŷ = w₁x + w₂x² + b`     | 平方的是 x（数据），w₁、w₂ 都是一次方       | ✅ 是（多项式回归）   |
| `ŷ = sin(w₁x) + b`       | w₁ 被关进了 sin 里面                        | ❌ 不是               |
| `ŷ = w₁² · x + b`        | w₁ 自己被平方了                             | ❌ 不是               |

**为什么这件事重要（不是文字游戏）**：关键在求解方式。参数都是一次方时，损失函数 MSE 对参数是一个规规矩矩的**碗**（凸函数），碗底唯一——§3 的正规方程才能"一步算出最优解"，§4 的梯度下降也保证走到全局最优。参数被套进 sin 或平方后，损失曲面变成**坑坑洼洼的山地**，闭式解直接失效，梯度下降还可能卡在某个小坑里出不来（这是后面神经网络要面对的核心困难）。

**前瞻**：§5 的多项式回归就是钻了这个空子——把 x²、x³ 提前算好当成新特征，"弯的数据"就能用线性回归的全套工具原封不动地解决。到 §5.2 会再见到这个判据，自测题第 5 题考的就是它。

**本节小结**："线性" = 对参数线性：每个参数一次方、乘以已知量、再相加。判据看参数姿态，不看图像直不直。对参数线性 → 损失是碗、有闭式解；不是 → 闭式解失效、只剩梯度下降硬磨。

## 2. 损失函数 MSE 🟢

### 2.1 是什么（直觉）

固定一组 (w, b)，直线就定了。它好不好？逐个点算"预测值和真实值差多少"（**误差** = y - ŷ），再把所有点的误差汇总成一个数。这个汇总规则就是损失函数。

最自然的想法是直接把误差加起来——不行，**正误差和负误差会互相抵消**（一套高估 10 万、一套低估 10 万，加起来 0，看起来完美，其实错得离谱）。那取绝对值？可以（这就是 §7 的 MAE），但绝对值函数在 0 点有个尖角，**数学上不好求导**，而优化算法全靠导数指路。所以主流选择是**平方**：

```
L(w, b) = (1/n) · Σᵢ (yᵢ - ŷᵢ)²      —— 均方误差 MSE（Mean Squared Error）
```

**逐符号翻译**：

- `yᵢ`：第 i 套房子的真实价格；`ŷᵢ = wxᵢ + b`：模型猜的价格；
- `(yᵢ - ŷᵢ)²`：第 i 套房的误差平方（平方后正负号消失，全变成正数）；
- `Σᵢ`：把 n 套房的误差平方全加起来；
- `(1/n)`：除以套数取平均——这样损失大小不随数据量变化，50 套房和 5 万套房的损失可以比；
- `L(w, b)`：强调损失是**参数的函数**——数据是固定的，w、b 一动，L 就变。优化的全部内容就是调 w、b 让 L 变小。

### 2.2 为什么用平方（三个理由）

1. **正负不抵消**：平方后误差全是正数，加总才有意义；
2. **放大较大的错误**：误差 2 → 贡献 4，误差 10 → 贡献 100。错得越离谱惩罚越狠（超线性），模型会优先修大错误；
3. **数学上好求导**：平方函数的导数是 `(u²)' = 2u`，干净光滑，处处可导——§4 的梯度下降全靠这一点。

代价也要知道：平方对**异常值**（比如数据里混进一套录错价格的豪宅）特别敏感，因为大误差被平方放大。这是 MSE 的固有性格，项目里遇到离群点要留意。

### 2.3 怎么用

```python
def mse(y_true, y_pred):
    return np.mean((y_true - y_pred) ** 2)   # 逐元素平方 → 求平均，就这一行

y_true = np.array([100, 200, 150])
pred_good = np.array([105, 195, 148])     # 猜得比较准
pred_bad  = np.array([130, 160, 190])     # 每套都差 30~40
print(mse(y_true, pred_good), mse(y_true, pred_bad))
# 18.0 1366.6666666666667 —— 差的预测损失大了 75 倍
```

注意"放大较大错误"在数字里很明显：good 组单个误差只有 5，bad 组单个误差 30~40（约 7 倍），但 MSE 差了约 75 倍（≈ 7² 的级别）。

### 2.4 和微积分文档的接口

回忆 `../阶段一/00-微积分前置知识.md` 的"下山"比喻：一座山，海拔就是损失值，你站在山上的位置由参数决定。**损失函数 L(w, b) 就是那座山**——w、b 各对应一个水平方向，L 是海拔。两个参数时它是一个碗状的曲面（MSE 是凸函数，碗底唯一，这是线性回归的福气），"训练"就是走到碗底。§3 是用公式瞬移到碗底，§4 是一步步走下去。

**本节小结**：MSE = 误差平方的平均，选平方是因为正负不抵消、放大较大的错误、好求导。损失函数是参数的函数，就是下山问题里的那座山。

## 3. 解法一：闭式解（正规方程）🟢

### 3.1 是什么（直觉）

既然碗底唯一，数学家干脆把"碗底的坐标"推导成了一个**公式**——不用迭代，把数据代入公式，**一步算出最优解**。这种"直接给答案的公式解"叫**闭式解**，在线性回归里它叫**正规方程**（Normal Equation）：

```
ŵ = (XᵀX)⁻¹Xᵀy
```

### 3.2 逐符号翻译（关键：增广矩阵）

先解决一个技术问题：模型里有 w 还有 b，公式里怎么只有一个 ŵ？**把 b 吸收进 w**——给数据矩阵 X 多拼一列全 1：

```
原来：ŷ = w₁x₁ + b
把 b 看成 "b × 1"，即给每套房加一个永远等于 1 的特征 x₀：
ŷ = b·x₀ + w₁x₁ = b·1 + w₁x₁
```

这样参数变成向量 **θ** = (b, w₁)，数据矩阵 X 第一列全 1（叫**增广矩阵**），模型统一写成 `ŷ = Xθ`。下面公式里的 X 都是指这个增广矩阵。

**逐符号翻译**（转置、逆矩阵的定义见 `../阶段一/00-线性代数前置知识.md`）：

- `X`：增广数据矩阵，形状 `(n, d)`——n 套房，d 列（第一列全 1，其余每列一个特征）；
- `y`：真实价格向量，形状 `(n,)`；
- `Xᵀ`：X 的转置，行列互换，形状 `(d, n)`——转置是为了让矩阵乘法维度对齐；
- `XᵀX`：形状 `(d, d)` 的方阵，可以理解为"特征之间的相关性表"；
- `(XᵀX)⁻¹`：`XᵀX` 的逆矩阵，矩阵版的"倒数"（`A·A⁻¹ = 单位矩阵`）；
- 整体读法：θ̂ = 先把 X 和 y 用 `Xᵀy` 关联起来，再"除掉" `XᵀX`（矩阵不能除，所以乘它的逆）。

它从哪来：损失 `L = (1/n)(y - Xθ)ᵀ(y - Xθ)` 对 θ 求导、令导数等于 0（碗底处坡度为 0），整理即得。推导过程阶段二不考，知道"**令梯度为 0 解出来的**"就够了。

### 3.3 怎么用（10 行跑通）

```python
x, y = area, price                          # 用 §1 造的房价数据
X_b = np.column_stack([np.ones(n), x])      # 增广矩阵：第一列全 1 吸收 b，形状 (50, 2)
theta = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y   # 正规方程，一行
b_hat, w_hat = theta
print(f"b = {b_hat:.4f}, w = {w_hat:.4f}")
# b = 27.2841, w = 1.5101 —— 真值是 b=30, w=1.5，学得很准！
```

和真实规律（1.5 和 30）对比：w 学到 1.5101，b 学到 27.28——差异来自我们故意加的市场噪声，这正是"从带噪声的数据中还原规律"。

**工程提示**：实际代码里求逆不直接写 `inv(A) @ b`，而用 `np.linalg.solve(X_b.T @ X_b, X_b.T @ y)`（更快更准）或 `np.linalg.lstsq(X_b, y, rcond=None)`（连 XᵀX 都不显式构造，最稳）——NumPy 文档 §8.2 说过"linalg 里工程上永远用 solve"，这里同样适用。手写练习时按公式写 `inv` 版本有助于理解，对答案用 `lstsq`。

### 3.4 优点与缺点

|                  | 说明                                                                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| ✅ 精确           | 一步到位算出数学上的最优解，没有"学习率""迭代次数"这些要调的旋钮                                                                         |
| ✅ 简单           | 一行公式，不用训练循环                                                                                                                   |
| ❌ 特征多了算不动 | 求 `(d, d)` 矩阵的逆，计算量约 d³。特征几千以内很快；上了十万特征就不可行                                                                |
| ❌ XᵀX 可能不可逆 | 两个特征完全重复（如"平米"和"平方英尺"同时收录）或特征数比样本还多时，逆不存在（数学上叫奇异矩阵），`lstsq` 能给出退化解，`inv` 直接报错 |

**什么时候用**：特征数少（几千以内）时闭式解是首选——这也是 sklearn 的 `LinearRegression` 默认就走这条路的原因。特征海量或样本海量时，换 §4 的梯度下降。

**本节小结**：正规方程 ŵ = (XᵀX)⁻¹Xᵀy 一步算出最优解；X 要拼一列全 1 把 b 吸收进参数向量。特征少用它，特征多或 XᵀX 不可逆时用梯度下降 / `lstsq`。

## 4. 解法二：梯度下降（核心）🟢

### 4.1 复习：下山直觉

微积分文档（`../阶段一/00-微积分前置知识.md`）讲过：**梯度指向损失上升最快的方向，负梯度就是下降最快的方向**。蒙眼下山的策略：每一步用脚探一圈，朝最陡的下坡方向挪一小步，重复直到谷底。

梯度下降就是把这件事写成循环：计算损失在当前参数处的梯度（各个方向上的坡度），然后**逆着梯度挪一小步**。

### 4.2 参数更新公式（逐符号翻译）

```
θ ← θ - η · ∂L/∂θ
```

- `θ`：参数向量（b 和所有 w 打包在一起）；
- `←`：赋值——用右边算出的新值替换旧值（就是代码里的 `theta = theta - ...`）；
- `η`（读作 eta）：**学习率**，一个你手动选定的小正数，控制每步迈多大；
- `∂L/∂θ`：损失 L 对参数 θ 的偏导数组成的向量，即梯度——" θ 里每个参数各自把 L 往上顶的速率"；
- 整体读法：**新参数 = 旧参数 - 步长 × 坡度**。坡度大（离底远）自动迈大步，坡度小（接近底）自动迈小步。

对线性回归 + MSE，梯度有现成的推导结论（推导思路见 §9）：

```
∂L/∂θ = -(2/n) · Xᵀ(y - ŷ)      其中 ŷ = Xθ
```

**大白话**：梯度 = 每个特征的"预测误差"按样本加总平均，再乘 -2。误差越大、特征值越大，这个方向上的修正就越猛。代码里就是一行矩阵运算。

### 4.3 怎么用（20 行跑通，亲眼看 loss 下降）

```python
x, y = area, price
x_s = x / 100                                # 把面积缩到 0.4~1.6，梯度量级温和，学习率好调（特征尺度太大会让梯度爆炸）
X_b = np.column_stack([np.ones(n), x_s])     # 增广矩阵
theta = np.zeros(2)                          # 参数从全 0 出发
lr = 0.1                                     # 学习率 η
for i in range(2000):
    y_pred = X_b @ theta                     # 当前参数下的预测
    grad = -2 / n * X_b.T @ (y - y_pred)     # 梯度公式，就是上面那行
    theta = theta - lr * grad                # 参数更新
    if i % 400 == 0 or i == 1999:
        print(f"第 {i:4d} 步: loss = {mse(y, X_b @ theta):9.4f}, theta = {theta.round(3)}")
# 第    0 步: loss = 12222.0039, theta = [36.935 41.854]
# 第  400 步: loss =   57.4289, theta = [ 28.209 150.165]
# 第  800 步: loss =   57.3479, theta = [ 27.298 150.993]
# 第 1200 步: loss =   57.3479, theta = [ 27.284 151.006]
# 第 1600 步: loss =   57.3479, theta = [ 27.284 151.006]
# 第 1999 步: loss =   57.3479, theta = [ 27.284 151.006]
print(f"b = {theta[0]:.4f}, w = {theta[1]/100:.4f}")   # w 缩过 100 倍，除回去
# b = 27.2841, w = 1.5101 —— 和 §3 闭式解的结果完全一致！
```

观察这条 loss 曲线：**12222 → 57.43 → 57.35，单调下降然后躺平**——前 400 步断崖式下降（离底远坡度陡），后面越来越慢（坡度平缓），最终停在 57.3479 不再动（到碗底了，梯度≈0）。57.35 正好是闭式解的损失，说明噪声水平决定了损失不可能降到 0——**损失有下限，下限 = 数据里的噪声**。

注意代码里 `x_s = x / 100` 这步**特征缩放**：面积的原始值是 40~160，梯度的量级被特征值放大上百倍，学习率会极难调。把特征缩放到相近的量级（比如都缩到 0~1 附近）是梯度下降前的标准动作（正式名字叫"特征归一化/标准化"，SciPy 文档里有现成工具）。

### 4.4 学习率：太大发散，太小爬不动

学习率 η 是梯度下降唯一（也最要命）的旋钮。同一组数据、同跑 2000 步，只改 η：

```python
for lr in [0.001, 0.1, 0.5]:
    theta = np.zeros(2)
    for i in range(2000):
        grad = -2 / n * X_b.T @ (y - X_b @ theta)
        theta = theta - lr * grad
    print(f"lr={lr}: 2000 步后 loss = {mse(y, X_b @ theta):.4f}")
# lr=0.001: 2000 步后 loss = 284.3345   —— 太小：方向对，但 2000 步还没走到（57.35 才是底）
# lr=0.1:   2000 步后 loss = 57.3479    —— 合适：稳定收敛到最优
# lr=0.5:   2000 步后 loss = 6.97e+240  —— 太大：一步跨过谷底冲到对面山坡，且比出发点更高，
#                                          下一步跨得更远……震荡发散，数字爆炸
```

**直觉**：下山时步子太大，不是走不到，而是**每一步都直接从山谷一侧蹦到另一侧更高的位置**，越蹦越高。工程判断法：loss 曲线震荡或变大 = 学习率砍小（常砍成 1/3 或 1/10）；loss 降得太慢 = 试着调大。

### 4.5 批量 vs 随机（SGD）vs mini-batch

上面每步都用全部 50 套房算梯度，叫**批量梯度下降（Batch GD）**。数据 50 条没问题，5000 万条时每挪一步都要把全量数据过一遍，太贵。按"每步看多少数据"分三派：

|                         | 每步用多少数据           | 类比                         | 特点                                                       |
| ----------------------- | ------------------------ | ---------------------------- | ---------------------------------------------------------- |
| 批量 GD                 | 全部 n 条                | 全班投票决定往哪走           | 方向准、稳；数据大时每步太贵                               |
| **SGD**（随机梯度下降） | 随机抽 **1** 条          | 随便问一个人就往他指的方向走 | 每步极快；方向抖，像醉汉下山，但总趋势向下                 |
| **mini-batch**          | 随机抽一小把（如 32 条） | 小组讨论                     | 工业界默认选择：抽样平均压住了抖动，又利用矩阵运算的并行性 |

**为什么随机抽一把也行？** 概率文档（`../阶段一/00-概率与数理统计前置知识.md`）的大数定律：随机样本的均值是总体均值的无偏估计——一小把样本算出的梯度，期望值等于全量梯度。所以 mini-batch 方向"平均而言是对的"，噪声在多次迭代中互相抵消。

SGD 完整示例（每步随机抽 1 套，跑 20 轮）：

```python
rng2 = np.random.default_rng(0)
theta = np.zeros(2)
for epoch in range(20):                      # epoch：把全部数据过一遍算一轮
    for j in rng2.permutation(n):            # 打乱顺序后逐个看
        xi = X_b[j]
        grad = -2 * xi * (y[j] - xi @ theta) # 单个样本的梯度（没有 /n，因为 n=1）
        theta = theta - 0.05 * grad
print(f"b = {theta[0]:.4f}, w = {theta[1]/100:.4f}, loss = {mse(y, X_b @ theta):.3f}")
# b = 25.5057, w = 1.4813, loss = 81.083 —— 接近但没精确收敛：SGD 会在最优点附近一直抖动
```

SGD 只用了 20×50 = 1000 次单样本计算就摸到了最优点附近（loss 81 vs 最优 57），但注意它**不会停在最优点**——单样本梯度在最优点也不为 0，参数会一直小步乱抖。工程上常用"越学学习率越小"（学习率衰减）来让它最后稳住。

### 4.6 术语表：epoch / batch / iteration

这三个词在所有深度学习资料里反复出现，一次分清：

- **epoch（轮）**：把全部训练数据完整过一遍。上面 SGD 跑了 20 个 epoch；
- **batch（批）**：一次参数更新所用的那一份数据。批量 GD 的 batch = 全部数据；SGD 的 batch = 1 条；mini-batch 的 batch = 一小把，batch 大小叫 **batch size**；
- **iteration / step（迭代/步）**：做一次参数更新。1 个 epoch 含 `ceil(n / batch_size)` 次迭代——50 条数据、batch size 8 时，1 个 epoch = 7 次迭代。

**本节小结**：梯度下降 = 反复执行 `θ ← θ - η·∂L/∂θ`，MSE 的梯度是 `-(2/n)·Xᵀ(y-ŷ)`。学习率太大发散、太小慢；loss 曲线单调下降并躺平 = 工作正常。按每步数据量分批量（准而贵）/ SGD（快而抖）/ mini-batch（默认选择）。epoch 过一遍全数据，iteration 更新一次参数。

## 5. 多项式回归与特征扩展 🟢

### 5.1 是什么（直觉）：数据是弯的怎么办

房价例子里的规律恰好是直线，幸运。但真实世界大量关系是弯的：学习时间和成绩（边际递减）、广告投入和销量（饱和）……一条直线硬套弯曲数据，怎么调 w、b 都拟合不好。

解法出人意料地简单：**把 x²、x³ 也当成新特征**，模型变成

```
ŷ = w₁x + w₂x² + w₃x³ + b
```

然后**原封不动地用线性回归求解**——闭式解、梯度下降都不改，只是 X 多了几列。

### 5.2 必须讲透的一点："线性"指对参数线性

初学者最容易误会的地方。**"线性回归"的"线性"不是说 y 和 x 的关系是直线，而是说模型对参数 w 是线性的**——每个 w 都只是"一次方、乘在特征上、再相加"。至于特征本身是 x、x² 还是 sin(x)，随便。

对照看：`ŷ = w₁x + w₂x² + b` 里，w₁、w₂ 都是规规矩矩的一次方 → 是线性回归；而 `ŷ = sin(w₁x) + b` 里参数 w₁ 被套进了 sin → **不是**线性回归，正规方程不适用，只能靠梯度下降硬磨。

所以多项式回归的本质是**特征扩展**：我们手工造了新特征（x²、x³……），把"弯的问题"转成"高维空间里的直的问题"。x² 这列数据和 x 一样是已知的、固定的数，模型眼里它们就是普通特征。

### 5.3 怎么用 + 过拟合 vs 欠拟合

造一批真实规律为抛物线 `y = 0.5x² + x + 2`（加噪声）的数据，故意切出 40 个训练、20 个测试，分别用 1 次、2 次、15 次多项式去拟合：

```python
rng3 = np.random.default_rng(42)
xp = rng3.uniform(-3, 3, 60)
yp = 0.5 * xp**2 + xp + 2 + rng3.normal(0, 1.5, 60)
xp_tr, xp_te, yp_tr, yp_te = xp[:40], xp[40:], yp[:40], yp[40:]   # 前 40 训练，后 20 测试

def poly_features(x, degree):
    # 特征扩展：把 x 变成 [x, x², ..., x^degree] 共 degree 列
    return np.column_stack([x ** d for d in range(1, degree + 1)])

for deg in [1, 2, 15]:
    Phi_tr = np.column_stack([np.ones(40), poly_features(xp_tr, deg)])
    Phi_te = np.column_stack([np.ones(20), poly_features(xp_te, deg)])
    th = np.linalg.lstsq(Phi_tr, yp_tr, rcond=None)[0]   # 还是线性回归，一行求解
    print(f"degree={deg:2d}: 训练MSE = {mse(yp_tr, Phi_tr @ th):8.3f}, "
          f"测试MSE = {mse(yp_te, Phi_te @ th):10.3f}")
# degree= 1: 训练MSE =    3.311, 测试MSE =      1.964
# degree= 2: 训练MSE =    1.213, 测试MSE =      1.406
# degree=15: 训练MSE =    0.634, 测试MSE =    145.331
```

这三行数字是机器学习的核心剧情，用学生考试类比：

- **degree=1（欠拟合 underfitting）**：拿直线套抛物线，训练误差就大（3.3）——**没学会**。模型太简单，规律就在眼前也抓不住；
- **degree=2（刚刚好）**：和真实规律同阶，训练、测试误差都最小——**学会了**，还泛化到了没见过的数据；
- **degree=15（过拟合 overfitting）**：训练误差 0.63 最低，测试误差 145 爆炸——**死记硬背**。15 次的曲线足够软，穿过几乎每个训练点（连噪声一起背下来），但在训练点之间疯狂扭动，遇到新数据一塌糊涂。

**核心判据：看训练误差和测试误差的组合**——

| 训练误差 | 测试误差 | 诊断   | 对策                                  |
| -------- | -------- | ------ | ------------------------------------- |
| 高       | 高       | 欠拟合 | 加特征、加多项式次数、换更强的模型    |
| 低       | 低       | 健康   | ——                                    |
| 低       | 高       | 过拟合 | 减特征/次数、加数据、**正则化**（§6） |

"把数据切成训练集和测试集，测试集假装是未来的新数据"，这个做法叫**留出法**，是评估一切模型的标准流程（Pandas 文档的数据切分和 §7 都会用到）。

**本节小结**：数据是弯的就把 x²、x³ 当新特征，模型仍是线性回归——"线性"指对参数线性，不是对 x。次数太低欠拟合（没学会，训练误差高），太高过拟合（死记硬背，训练误差低但测试误差爆炸），诊断看训练/测试误差组合。

## 6. 正则化 Ridge / Lasso 🟢

### 6.1 是什么（直觉）

§5 的过拟合还有个特征：15 次多项式的参数 w 往往**绝对值巨大**（几百万、正负交替），靠大数互相抵消来精确穿过训练点。参数太"野" = 模型太野。

正则化的思路像给合同加条款：**在损失函数里加一条"参数越大罚款越多"**，模型为了少交罚款，会主动把参数收敛得温和一些：

```
带罚款的损失 = MSE + λ × 罚款项(θ)
```

- **罚款项**是参数的某种"大小"的度量（两种主流选法见下）；
- **λ（lambda）**：**超参数**——不由数据学出来、由你事先设定的数，控制罚款力度。λ=0 就是普通线性回归；λ 越大参数被压得越扁；λ 太大模型躺平（全学成 0，欠拟合）。调 λ 就是调"拟合数据"和"参数温和"之间的天平。

> "超参数" vs "参数"：参数（w、b）是优化算法从数据里学出来的；超参数（λ、学习率、多项式次数）是你拍脑袋/试出来的，训练开始前就定好。

### 6.2 Ridge（L2）vs Lasso（L1）

|          | Ridge（岭回归）                                | Lasso                                                     |
| -------- | ---------------------------------------------- | --------------------------------------------------------- |
| 罚款项   | λ·Σwⱼ²（参数的**平方和**，叫 L2）              | λ·Σ\|wⱼ\|（参数的**绝对值之和**，叫 L1）                  |
| 效果     | 所有参数都**按比例缩小**，但几乎不会恰好变 0   | 能把不重要特征的参数**直接罚成 0**                        |
| 附带价值 | 缓解 XᵀX 不可逆问题（加上 λI 后必可逆）        | **自动特征选择**：参数为 0 的特征等于被开除了             |
| 求导     | 平方处处光滑可导，有闭式解 θ̂ = (XᵀX + λI)⁻¹Xᵀy | 绝对值在 0 点不可导，只能用迭代算法（sklearn 内部已处理） |

为什么 L1 能罚成 0 而 L2 不能？直觉：**平方罚款对快变 0 的参数"手会变软"**——0.01 的平方是 0.0001，参数越小罚款的推力越微弱，最后悬停在接近 0 的地方；**绝对值罚款的推力恒定**——不管参数是 100 还是 0.01，减少它的收益都是 λ，于是一路把不重要的参数推到 0 才罢休。

用数据亲眼看（6 个特征，其实只有前 3 个有用）：

```python
from sklearn.linear_model import Ridge, Lasso

rng4 = np.random.default_rng(0)
X_r = rng4.normal(0, 1, (80, 6))
y_r = X_r @ np.array([3.0, -2.0, 1.5, 0.0, 0.0, 0.0]) + rng4.normal(0, 0.5, 80)
#                                     ↑ 后 3 个特征的真实参数就是 0（没用）

ridge = Ridge(alpha=1.0).fit(X_r, y_r)     # sklearn 里 λ 叫 alpha
lasso = Lasso(alpha=0.1).fit(X_r, y_r)
print("Ridge:", ridge.coef_.round(3))
# Ridge: [ 2.995 -2.01   1.445 -0.001  0.    -0.045]  —— 没用的参数被压小，但没变 0
print("Lasso:", lasso.coef_.round(3))
# Lasso: [ 2.942 -1.939  1.366 -0.     0.    -0.   ]  —— 没用的参数被精确罚成 0！
```

Lasso 自动发现了"后 3 个特征是废物"——这就是**特征选择**。特征成百上千、怀疑大部分是噪声时，Lasso 是首选侦察兵。

**本节小结**：正则化 = 损失 + λ×罚款项，λ 是超参数控制力度。Ridge 罚平方和（参数都缩小不归零，有闭式解），Lasso 罚绝对值和（能把废特征参数罚成 0，等于自动特征选择）。

## 7. 模型评估 🟢

模型训好了，怎么汇报"它有多好"？

### 7.1 MSE / RMSE / MAE：三个误差指标

```python
X_b = np.column_stack([np.ones(n), x])      # 原始尺度（不除 100）的房价数据
theta = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
y_pred = X_b @ theta
resid = y - y_pred                           # 残差：真实 - 预测

mse_v  = np.mean(resid ** 2)                 # 57.348
rmse_v = np.sqrt(mse_v)                      # 7.573
mae_v  = np.mean(np.abs(resid))              # 6.289
```

| 指标 | 公式             | 单位                              | 性格                                     |
| ---- | ---------------- | --------------------------------- | ---------------------------------------- |
| MSE  | 误差平方的均值   | **万²**（平方后单位变了，不直观） | 训练时的损失函数；对大误差惩罚狠         |
| RMSE | √MSE             | **万**（开方把单位救回来）        | "平均来说猜偏约 7.6 万"，业务汇报首选    |
| MAE  | 误差绝对值的均值 | **万**                            | 比 RMSE 抗异常值；0 点不可导，少用作损失 |

记法：**MSE 用来训练，RMSE/MAE 用来汇报**。三者越小越好，但绝对数值依赖问题本身（房价的 7 万和气温的 7 度没法比），所以还需要一个"归一化"的指标——R²。

### 7.2 R²（决定系数）：比瞎猜好多少

最朴素的预测是什么？不看任何特征，**直接猜平均值**（所有房子都猜 ȳ）。R² 回答的问题就是：**你的模型比这个"瞎猜基线"好多少**：

```
R² = 1 - Σ(yᵢ - ŷᵢ)² / Σ(yᵢ - ȳ)²
```

**逐符号翻译**：

- 分母 `Σ(yᵢ - ȳ)²`：用均值瞎猜的总误差（ȳ 是 y 的均值）——数据本身的"天然波动"，是不可推卸的基线；
- 分子 `Σ(yᵢ - ŷᵢ)²`：你的模型的总误差（就是 n×MSE）；
- 比值 = 你的误差 ÷ 瞎猜的误差；1 减去它 = **你的模型把天然波动解释掉了多少比例**。

读数规则：

- **R² = 1**：完美预测，误差为 0；
- **R² = 0**：和瞎猜一模一样，模型白训了；
- **R² < 0**：比瞎猜还差（比如模型在没见过的新数据上彻底翻车）——红灯；
- 房价例子算出 **R² = 0.9779**：模型解释了 97.8% 的价格波动，相当好。

```python
r2 = 1 - np.sum(resid**2) / np.sum((y - y.mean())**2)
print(f"R² = {r2:.4f}")     # R² = 0.9779
```

### 7.3 残差分析：看模型漏掉了什么

**残差 = 真实值 - 预测值**（就是上面的 `resid`），是每个样本"模型没解释掉的部分"。如果模型把规律抓全了，剩下的应该**纯是随机噪声**；如果残差里还有规律，说明模型漏掉了信息，而且这个规律直接告诉你往哪改。

标准做法（呼应 `../阶段一/02-Matplotlib前置学习文档.md` 的散点图）：**画"预测值 vs 残差"散点图**，加一条 y=0 的横线，看点的分布：

```python
import matplotlib.pyplot as plt

plt.scatter(y_pred, resid, s=15)
plt.axhline(0, color='red')
plt.xlabel('预测值'); plt.ylabel('残差'); plt.title('残差图')
plt.show()
# 健康：点随机分布在 0 线上下，无明显形状、无明显喇叭口
```

| 残差图长相                 | 诊断           | 对策               |
| -------------------------- | -------------- | ------------------ |
| 随机一团，0 线上下均匀     | ✅ 模型抓全了   | ——                 |
| 呈 U 形 / 倒 U 形          | 漏掉了弯曲规律 | 加多项式特征（§5） |
| 喇叭口（预测越大残差越散） | 噪声随量级变大 | 对 y 取 log 再回归 |
| 残差随某个没用的特征变化   | 漏掉了重要特征 | 把那个特征加进来   |

残差的均值应约为 0（我们的例子 `resid.mean()` ≈ 2.8e-13，就是 0 加上浮点误差）——数学上保证了线性回归（带 b 时）残差均值必为 0，所以这个检查没信息量，**看形状才是残差分析的灵魂**。

**本节小结**：训练看 MSE，汇报用 RMSE/MAE（单位和业务一致），横向比较用 R²（1 最好、0 等于猜均值、负数比瞎猜差）。残差图应该是随机噪声；出现形状 = 模型漏了信息，形状直接指向修法。

## 8. sklearn 速查 🟡

手写练习的对答案工具。sklearn 所有模型的 API 统一成三个方法：`fit(X, y)` 训练、`predict(X)` 预测、`score(X, y)` 打分（回归模型的 score 就是 R²）。**注意 sklearn 的 X 必须是二维 `(n样本, n特征)`**，一维特征要 `x.reshape(-1, 1)`；截距 b 自动包含（`fit_intercept=True` 是默认），不用自己拼全 1 列。

```python

from sklearn.preprocessing import PolynomialFeatures
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

X_2d = x.reshape(-1, 1)                      # (50,) → (50, 1)，sklearn 强制要求

# ① 闭式解版本（内部走 lstsq 类的数值方法）
m = LinearRegression().fit(X_2d, y)
m.intercept_, m.coef_          # 27.2841, array([1.5101]) —— b 和 w，与 §3 手写一致
m.score(X_2d, y)               # 0.9779 —— score 就是 R²

# ② 随机梯度下降版本（大数据用；对特征尺度敏感，实战先标准化）
sgd = SGDRegressor(max_iter=1000, random_state=42).fit(X_2d, y)

# ③ 正则化版本（alpha 就是 λ）
Ridge(alpha=1.0).fit(X_2d, y)                # L2
Lasso(alpha=0.1).fit(X_2d, y)                # L1

# ④ 多项式特征扩展（就是 §5 手工 poly_features 的官方版）
poly = PolynomialFeatures(degree=2, include_bias=False)
print(poly.fit_transform(np.array([[2.0], [3.0]])))
# [[2. 4.] [3. 9.]] —— 每个 x 扩展成 [x, x²]
# 标准套路：PolynomialFeatures 先扩展特征，再喂给 LinearRegression —— 多项式回归

# ⑤ 评估指标
mean_squared_error(y, m.predict(X_2d))       # 57.3479（新版本没有 squared=False 参数，
np.sqrt(mean_squared_error(y, y_pred))       # 7.5728  ← RMSE 自己开方）
mean_absolute_error(y, m.predict(X_2d))      # 6.2891
r2_score(y, m.predict(X_2d))                 # 0.9779 —— 与 §7 手算完全一致
```

**对答案姿势**：手写实现的 w、b、MSE、R²，用 `np.allclose` 和 sklearn 的结果对比（NumPy 文档 §10.5：浮点比较永远 `allclose`）。本文已验证三方一致：手写闭式解 b=27.2841/w=1.5101 = 手写梯度下降收敛值 = sklearn `LinearRegression`。

**本节小结**：sklearn 统一 `fit/predict/score` 三件套，X 要二维。`LinearRegression`（闭式解）、`SGDRegressor`（大数据）、`Ridge/Lasso`（alpha=λ）、`PolynomialFeatures`（特征扩展）、`mean_squared_error/r2_score`（评估）。

## 9. 手写练习预告

接下来在 `algorithms/linear_regression/` 里仅用最 NumPy 手写三样东西，本文的公式就是设计图：

| 要手写的文件                   | 对应本文公式          | 核心一行代码                                       |
| ------------------------------ | --------------------- | -------------------------------------------------- |
| 闭式解 `closed_form.py`        | ŵ = (XᵀX)⁻¹Xᵀy（§3）  | `np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y`           |
| 梯度下降 `gradient_descent.py` | θ ← θ - η·∂L/∂θ（§4） | `theta -= lr * (-2/n * X_b.T @ (y - X_b @ theta))` |
| 评估指标 `metrics.py`          | MSE/RMSE/MAE/R²（§7） | `1 - np.sum(resid**2) / np.sum((y-y.mean())**2)`   |

对答案：三者互相印证 + sklearn 复核（§8），通过标准 = `np.allclose` 全 True。

**梯度公式推导思路（结论必须记住，过程看懂即可）**：

损失 `L = (1/n)Σᵢ(yᵢ - θ·xᵢ)²`（把 b 吸收进 θ 后模型是 θ·xᵢ）。对 θ 求偏导：

1. **链式法则**（`../阶段一/00-微积分前置知识.md`）：外层是平方，`(u²)' = 2u`，这里 u = yᵢ - θ·xᵢ；
2. 内层 u 对 θ 求导：yᵢ 是常数导数为 0，θ·xᵢ 对 θ 的导数是 xᵢ，所以 u' = -xᵢ；
3. 合起来：单个样本贡献 `2(yᵢ - θ·xᵢ)·(-xᵢ)` = `-2xᵢ(yᵢ - ŷᵢ)`；
4. 全部 n 个样本求和、再乘 1/n：`∂L/∂θ = -(2/n)Σᵢ xᵢ(yᵢ - ŷᵢ)`；
5. 把求和写成矩阵形式（转置 × 向量，线性代数文档）：**`∂L/∂θ = -(2/n)·Xᵀ(y - ŷ)`**。

对照 §4 的代码 `grad = -2 / n * X_b.T @ (y - y_pred)`——公式和代码逐字符对应，这就是"公式翻译成代码"的完整示范。

## 完整速查表

**概念**：模型 ŷ = w·x + b（b 靠增广矩阵拼全 1 列吸收）｜ 损失函数 MSE = (1/n)Σ(y-ŷ)² ｜ 训练 = 找让损失最小的参数 ｜ 超参数（λ、学习率、多项式次数）人定，参数（w、b）机器学

**公式**：

| 名称     | 公式                              | 一句话                     |
| -------- | --------------------------------- | -------------------------- |
| 模型     | ŷ = w·x + b                       | 一次函数 / 向量点积        |
| MSE      | (1/n)Σ(yᵢ-ŷᵢ)²                    | 误差平方的平均             |
| 正规方程 | ŵ = (XᵀX)⁻¹Xᵀy                    | 一步算出最优解（特征少用） |
| 梯度     | ∂L/∂θ = -(2/n)·Xᵀ(y-ŷ)            | MSE 对参数的偏导           |
| 参数更新 | θ ← θ - η·∂L/∂θ                   | 逆着坡度挪一小步           |
| Ridge    | MSE + λΣwⱼ²，闭式解 (XᵀX+λI)⁻¹Xᵀy | 参数缩小不归零             |
| Lasso    | MSE + λΣ\|wⱼ\|                    | 废特征参数罚成 0           |
| R²       | 1 - Σ(y-ŷ)²/Σ(y-ȳ)²               | 比猜均值好多少             |

**代码**：

| 需求         | NumPy 手写                                      | sklearn                             |
| ------------ | ----------------------------------------------- | ----------------------------------- |
| 闭式解       | `np.linalg.inv(X_b.T@X_b)@X_b.T@y`              | `LinearRegression().fit(X, y)`      |
| 求稳解法     | `np.linalg.lstsq(X_b, y, rcond=None)`           | 同上（内部就是它）                  |
| 梯度         | `-2/n * X_b.T @ (y - X_b@theta)`                | `SGDRegressor()`                    |
| 正则化       | Ridge 闭式解换 `X_b.T@X_b + λ*np.eye(d)`        | `Ridge(alpha=λ)` / `Lasso(alpha=λ)` |
| 多项式特征   | `np.column_stack([x**d for d in range(1,k+1)])` | `PolynomialFeatures(degree=k)`      |
| MSE/RMSE/MAE | `mean(r**2)` / `sqrt` / `mean(abs(r))`          | `mean_squared_error` 等             |
| R²           | `1 - sum(r**2)/sum((y-y.mean())**2)`            | `r2_score` / `model.score`          |

## 自测题（附答案）

1. **（三角色）** "线性回归的训练"具体指什么？模型、损失函数、优化算法各对应本文的哪个具体对象？
2. **（MSE）** 为什么损失函数用误差平方而不是误差直接求和、也不用绝对值？（说出三条理由）
3. **（增广矩阵）** 正规方程 ŵ = (XᵀX)⁻¹Xᵀy 里没有 b，b 去哪了？X_b = np.column_stack([np.ones(n), x]) 这行代码在做什么？
4. **（梯度下降诊断）** 训练时 loss 曲线先是 12222，下一步变成 1e+10，再下一步 1e+20——发生了什么？怎么修？如果 loss 从 12222 每步只降 0.1 呢？
5. **（"线性"的含义）** ŷ = w₁x + w₂x² + b 和 ŷ = sin(w₁x) + b，哪个是线性回归？为什么？
6. **（过拟合）** 某模型训练 MSE = 0.6、测试 MSE = 145。诊断结论？说出至少两种对策。
7. **（正则化）** 特征有 500 个，怀疑其中大部分是噪声，想顺便把没用的特征筛掉——选 Ridge 还是 Lasso？为什么？
8. **（R²）** 模型 A 的 R² = 0.85，模型 B 的 R² = -0.2。分别说明什么？R² 的分母是什么含义？

### 参考答案

**1.** 训练 = 用优化算法找到让损失函数最小的参数 w、b。模型：ŷ = wx + b（或 ŷ = w·x + b）；损失函数：MSE = (1/n)Σ(y-ŷ)²；优化算法：闭式解（正规方程）或梯度下降。

**2.** ①直接求和正负误差互相抵消，错得再多也可能加出 0；②平方放大较大的错误（误差 10 贡献 100），模型优先修大错误；③平方处处光滑可导，梯度下降能用——绝对值在 0 点有尖角不可导。

**3.** b 被"吸收"进了参数向量：把 b 看成 b×1，给每行数据加一个恒为 1 的特征 x₀，参数变成 θ=(b, w₁)。`column_stack([np.ones(n), x])` 就是在 X 左边拼一列全 1（增广矩阵），让 ŷ = Xθ 一个矩阵乘法同时包含 w 和 b。

**4.** loss 爆炸 = 学习率太大，每步跨过谷底落在对面更高的山坡，震荡发散；修法：学习率砍小（如 1/10），并检查特征尺度（必要时先做归一化）。loss 降得极慢 = 学习率太小，调大试试。

**5.** 第一个是，第二个不是。"线性"指模型对**参数**线性：w₁、w₂ 都是一次方乘以已知特征再相加（x² 只是提前算好的新特征）。sin(w₁x) 把参数套进了非线性函数，对参数不是线性，正规方程失效。

**6.** 典型过拟合（训练误差低、测试误差爆炸 = 死记硬背）。对策：①降低多项式次数/减少特征；②加正则化（Ridge/Lasso）；③增加训练数据。

**7.** 选 Lasso。L1（绝对值罚款）推力恒定，能把不重要特征的参数精确罚到 0，等于自动特征选择；Ridge 的 L2（平方罚款）在参数接近 0 时推力衰减，参数只会缩得很小但不归零，筛不出特征。

**8.** A：模型解释了 85% 的数据波动，远好于瞎猜，不错。B：R² < 0 说明比"直接猜均值"还差，模型在这份数据上是负资产（常见于过拟合模型碰到新数据）。分母 Σ(yᵢ-ȳ)² 是"用均值瞎猜的总误差"，即数据自身的天然波动，充当基线。
